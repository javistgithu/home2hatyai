# การเก็บข้อมูลประกาศ — สิ่งที่ทำได้ และสิ่งที่ไม่ควรทำ

> เอกสารนี้สำคัญ อ่านก่อนตั้งระบบเก็บข้อมูล

---

## สรุปสั้น ๆ

การเขียนบอทไล่ดูดโพสต์จากกลุ่ม Facebook ที่คุณไม่ได้เป็นแอดมิน
**ผิดข้อกำหนดการใช้งานของ Meta** และมีผลจริงคือบัญชีหรือเพจถูกระงับ
ระบบนี้จึงไม่มีเครื่องมือแบบนั้นให้ และออกแบบช่องทางที่ทำได้จริงไว้แทน 4 ทาง

| ช่องทาง | ใช้เมื่อไหร่ | ความเสี่ยง |
|---------|--------------|------------|
| Facebook Graph API | กลุ่ม/เพจที่คุณเป็นแอดมิน | ปลอดภัย — เป็นช่องทางที่ Meta เปิดให้ |
| คัดลอกข้อความมาวาง | เก็บทีละไม่กี่โพสต์ | ปลอดภัย — คนทำเอง |
| ไฟล์ CSV / JSON | ย้ายข้อมูลจากระบบเดิม | ปลอดภัย |
| ผู้ขายลงประกาศเอง | ให้เจ้าของทรัพย์กรอกเอง | ปลอดภัยที่สุด และข้อมูลแม่นที่สุด |

---

## ทำไมถึงไม่ทำตัวดูดข้อมูลอัตโนมัติให้

**1. ผิดข้อกำหนดของ Meta**
ข้อกำหนดการใช้งานของ Facebook ห้ามเก็บข้อมูลอัตโนมัติโดยไม่ได้รับอนุญาตเป็นลายลักษณ์อักษร
รวมถึงการใช้บัญชีจริงล็อกอินผ่านสคริปต์เพื่อเข้าถึงเนื้อหาในกลุ่ม

**2. ผลกระทบจริงที่เกิดขึ้น**
บัญชีถูกล็อก เพจถูกจำกัดการเข้าถึง ถูกเตะออกจากกลุ่ม
สำหรับธุรกิจนายหน้าที่พึ่งพา Facebook เป็นช่องทางหลัก ความเสียหายนี้มากกว่าประโยชน์ที่ได้

**3. พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA)**
โพสต์ขายบ้านมีชื่อและเบอร์โทรของบุคคล ซึ่งเป็นข้อมูลส่วนบุคคล
การเก็บและนำไปแสดงต่อต้องมีฐานทางกฎหมายรองรับ และเจ้าของข้อมูลมีสิทธิ์ขอให้ลบได้

**4. คุณภาพข้อมูล**
ข้อมูลที่ดูดมามั่ว ๆ มักซ้ำ เก่า และไม่ครบ
ข้อมูลที่ได้รับความยินยอมจากผู้ขายมีคุณภาพสูงกว่ามาก และผู้ขายยินดีอัปเดตให้เอง

## วิธีที่ 1 — Facebook Graph API (กลุ่ม/เพจของคุณเอง)

### เตรียมการ
1. สร้างแอปที่ [developers.facebook.com](https://developers.facebook.com) → เลือกประเภท **Business**
2. เพิ่มผลิตภัณฑ์ **Facebook Login**
3. ขอสิทธิ์ (permission) ตามชนิดที่จะเก็บ
   - กลุ่ม: `groups_access_member_info`, `publish_to_groups`
   - เพจ: `pages_read_engagement`, `pages_show_list`
4. **ติดตั้งแอปเข้ากับกลุ่ม** — ที่กลุ่ม → การตั้งค่า → แอป → เพิ่มแอป
   (ขั้นตอนนี้ทำได้เฉพาะแอดมินกลุ่ม และเป็นเหตุผลว่าทำไมวิธีนี้ใช้กับกลุ่มคนอื่นไม่ได้)
5. สร้าง access token ที่ [Graph API Explorer](https://developers.facebook.com/tools/explorer/)
   แล้วแลกเป็น long-lived token

### รันตัวเก็บข้อมูล
```bash
export FB_ACCESS_TOKEN=EAAxxxxx
export FB_GROUP_IDS=1234567890,9876543210
export APP_URL=https://your-app.vercel.app
export INGEST_SECRET=<ค่าเดียวกับฝั่งเซิร์ฟเวอร์>
export SINCE_DAYS=7

npm run collect:facebook
```

ผลลัพธ์ที่ได้จะบอกว่าเก็บมากี่โพสต์ สร้างประกาศใหม่กี่รายการ ซ้ำกี่รายการ

### ข้อจำกัดที่ควรรู้
- Meta ปิดการเข้าถึงฟีดกลุ่มไปหลายส่วนตั้งแต่ปี 2022 บาง endpoint อาจใช้ไม่ได้แล้ว
- แอปต้องผ่าน App Review ก่อนใช้กับผู้ใช้ทั่วไป
- มีโควตาจำกัดจำนวนคำขอต่อชั่วโมง

## วิธีที่ 2 — คัดลอกข้อความมาวาง

เร็วที่สุดสำหรับการเก็บทีละไม่กี่โพสต์ และไม่มีความเสี่ยงใด ๆ

1. เข้าหน้า **แอดมิน → นำเข้าข้อมูล**
2. คัดลอกข้อความโพสต์มาวาง คั่นแต่ละโพสต์ด้วยบรรทัดที่มีขีดสามอัน `---`
3. กดนำเข้า ระบบจะแสดงผลการแปลงทีละรายการพร้อมคำเตือน

รับได้สูงสุด 100 โพสต์ต่อครั้ง

## วิธีที่ 3 — ไฟล์ CSV / JSON

```bash
npx tsx scripts/import-posts.mjs posts.csv --source-name "กลุ่มบ้านหาดใหญ่" --kind facebook_group
```

**CSV** ต้องมีคอลัมน์ `content` เป็นอย่างน้อย รองรับเพิ่มเติม:
`external_post_id`, `permalink`, `author_name`, `posted_at`, `images` (คั่นด้วย `|`)

**JSON** เป็นอาร์เรย์ของอ็อบเจกต์รูปแบบเดียวกัน — ดูตัวอย่างที่ `scripts/sample-posts.json`

## วิธีที่ 4 — API สำหรับตัวเก็บข้อมูลภายนอก

ถ้าคุณมีระบบเก็บข้อมูลของตัวเองอยู่แล้ว ส่งเข้ามาที่ `POST /api/ingest`

```
POST /api/ingest
x-ingest-timestamp: 1757400000000
x-ingest-signature: sha256=<HMAC-SHA256 ของ "timestamp.body" ด้วย INGEST_SECRET>
content-type: application/json

{
  "source": { "kind": "facebook_group", "name": "ชื่อกลุ่ม", "external_id": "123" },
  "posts": [
    { "content": "ขายบ้าน...", "external_post_id": "abc", "posted_at": "2026-09-01T10:00:00Z" }
  ],
  "options": { "autoPublish": false, "useGeocoding": true, "dedupe": true }
}
```

ลายเซ็นมีอายุ 5 นาทีเพื่อกันการดักคำขอไปยิงซ้ำ
ตัวช่วยลงลายเซ็นอยู่ที่ `scripts/lib-ingest-client.mjs`

## แนวทางที่แนะนำจริง ๆ สำหรับธุรกิจนายหน้า

เรียงจากได้ผลดีที่สุด

1. **เชิญผู้ขายมาลงประกาศเอง** — ส่งลิงก์หน้าลงประกาศให้ในแชท
   ผู้ขายกรอกเอง ปักหมุดเอง ข้อมูลแม่นและอัปเดตตลอด
2. **ขอความยินยอมเป็นข้อความ** — ถ้าจะเอาโพสต์ของคนอื่นมาลง
   ทักไปขออนุญาตก่อน แล้วเก็บหลักฐานการอนุญาตไว้
3. **ทำกลุ่มของตัวเอง** — เมื่อคุณเป็นแอดมินกลุ่ม จะใช้ Graph API ได้เต็มที่
4. **แลกข้อมูลกับนายหน้าเจ้าอื่น** — ตกลงกันเป็นทางการแล้วนำเข้าผ่าน CSV

## สิ่งที่ระบบทำให้เพื่อลดความเสี่ยง PDPA

- เก็บ **ที่มาของทุกประกาศ** ไว้ในตาราง `raw_posts` พร้อมลิงก์โพสต์ต้นทาง —
  ตรวจสอบย้อนหลังได้ว่าข้อมูลมาจากไหน
- ข้อมูลดิบเปิดให้ **แอดมินเท่านั้น** (บังคับด้วย RLS) ผู้ใช้ทั่วไปเข้าไม่ถึง
- **ซ่อนเบอร์โทรไว้ก่อน** ผู้ซื้อต้องกดจึงจะเห็น ลดการดูดเบอร์อัตโนมัติ
- แอดมิน **ลบประกาศได้ทันที** เมื่อเจ้าของข้อมูลร้องขอ
- หน้าประกาศแสดงข้อความกำกับว่าข้อมูลรวบรวมจากประกาศสาธารณะ

### เมื่อมีคนขอให้ลบข้อมูล
```sql
-- ลบประกาศและโพสต์ดิบทั้งหมดที่มาจากเบอร์นั้น
delete from public.listings where contact_phone_normalized = '0812345678';
delete from public.raw_posts where content like '%0812345678%';
```
