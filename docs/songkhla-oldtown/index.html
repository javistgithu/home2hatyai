พิกัดที่คุณบันทึกไว้

ทุกครั้งที่คุณกรกดปุ่ม บันทึกพิกัดจุดนี้ ตอนยืนอยู่หน้าร้าน หน้านี้จะเก็บพิกัด GPS จริงไว้ในเครื่อง เดินครบย่านก็จะได้ชุดพิกัดจริงทั้งหมดที่ไม่มีในเว็บไหน ก๊อปข้อความข้างล่างส่งกลับมาให้ผมได้เลย เดี๋ยวผมทำเป็นไฟล์ KML ให้ import เข้า Google My Maps แบบพิกัดเป๊ะ
