# แผนธุรกิจ + การลงทุน (home2hatyai)

ชุดเอกสารและเครื่องมือติดตามผลรายวัน สำหรับธุรกิจนายหน้า/lead-gen อสังหาฯ หาดใหญ่

| ไฟล์ | คืออะไร |
|---|---|
| `PLAN.md` | แผนฉบับเต็ม — ตรรกะ ตัวเลข และลำดับการลงมือ **อ่านไฟล์นี้ก่อน** |
| `build_tracker.py` | สคริปต์สร้างไฟล์ตัวติดตาม (.xlsx) ขึ้นมาใหม่ |
| `home2hatyai-plan-tracker.xlsx` | ไฟล์ที่สร้างแล้ว — อัปโหลดเข้า Google Drive ได้เลย |
| `apps-script/daily-line-report.gs` | ตัวเลือกเสริม: ส่งสรุปประจำวันเข้า LINE ตอน 20:00 น. |

## 9 แท็บในชีต

1. **เริ่มที่นี่** — อ่านครั้งเดียว 5 นาที
2. **แดชบอร์ด** — ไฟสัญญาณ 3 ดวง + ตัวชี้วัด วันนี้ / 7 วัน / 30 วัน / เดือนนี้ / ตั้งแต่เริ่ม
3. **บันทึกรายวัน** — 370 วันเตรียมไว้แล้ว กรอกวันละ 8 ช่อง แถววันนี้ไฮไลต์อัตโนมัติ
4. **ดีลในมือ** — ท่อการขาย 60 ดีล คำนวณมูลค่าถ่วงน้ำหนักตามสถานะ
5. **พอร์ตลงทุน** — 5 ชั้นความเสี่ยง + บอกว่าต้องซื้อ/ขายอะไรให้ตรงเป้า
6. **มูลค่าพอร์ตรายวัน** — กำไรสะสมและ Drawdown
7. **ตั้งค่า** — สมมติฐานทั้งหมดอยู่ที่เดียว แก้ตรงนี้ ทั้งไฟล์เปลี่ยนตาม
8. **กฎเหล็ก** — 15 กฎกันเจ๊ง พร้อมช่องติ๊กสถานะ
9. **แผน12เดือน** — เส้นทางเดือนต่อเดือน คำนวณจากสมมติฐานอัตโนมัติ

## สร้างไฟล์ใหม่

```bash
pip install openpyxl
python3 build_tracker.py      # ได้ home2hatyai-plan-tracker.xlsx
```

แก้วันเริ่มต้นหรือจำนวนวันได้ที่ตัวแปร `START` และ `NDAYS` ด้านบนของสคริปต์

## เปิดใน Google Sheets

อัปโหลดไฟล์ `.xlsx` เข้า Google Drive แล้วเปิดด้วย Google Sheets
(Drive จะแปลงให้อัตโนมัติ พร้อมสูตร รูปแบบ เมนูดรอปดาวน์ และการไฮไลต์ตามเงื่อนไข)

## ข้อจำกัด

เอกสารและชีตชุดนี้เป็นเครื่องมือวางแผนและติดตามผล **ไม่ใช่คำแนะนำการลงทุนเฉพาะบุคคล
และไม่ใช่คำแนะนำด้านภาษี** ตัวเลขตั้งต้นเป็นสมมติฐานเพื่อให้เริ่มใช้งานได้ทันที
ตรวจอัตราดอกเบี้ย เงื่อนไขกองลดหย่อนภาษี และใบอนุญาตผู้ขายของจริง
ที่ rd.go.th และ sec.or.th ก่อนตัดสินใจทุกครั้ง
