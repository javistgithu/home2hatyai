# 01 — ธีสิสธุรกิจ ตลาดหาดใหญ่ และกลุ่มลูกค้า

---

## 1.1 ธีสิสธุรกิจ (สิ่งที่เราเชื่อ และคนอื่นยังไม่ทำ)

### ปัญหาจริงของตลาดนี้

ในตลาดบ้านมือสองราคา 1–3 ล้านบาท กลุ่มผู้ซื้อคือคนที่ปัจจุบัน **เช่าบ้านอยู่** และมีเงินผ่อนได้เดือนละ 5,000–15,000 บาท
คนกลุ่มนี้ "อยากมีบ้าน" มานานแล้ว แต่ไม่ได้บ้านเพราะเหตุผลเดียวกันซ้ำๆ:

| อุปสรรคจริง | สัดส่วนที่พบ (ประมาณการ ต้องวัดจริง) | นายหน้าทั่วไปทำอะไร |
|---|---|---|
| ยื่นกู้ไม่ผ่าน (DSR สูง / บูโรมีประวัติ / ไม่มีเอกสารรายได้) | สูงที่สุด | ทิ้งลูกค้า ไปหาคนใหม่ |
| ไม่มีเงินก้อนวันโอน (ค่าโอน ค่าจดจำนอง ประกัน มิเตอร์) | สูง | ไม่ได้แจ้งล่วงหน้า → ดีลล่มวันโอน |
| ธนาคารประเมินราคาต่ำกว่าราคาขาย | ปานกลาง | โทษลูกค้า |
| กลัวบ้านมือสอง (ผี, น้ำท่วม, ซ่อมไม่จบ) | สูงมากในหาดใหญ่ | ปิดข้อมูล → ลูกค้ารู้ทีหลัง → เสียชื่อ |
| ไม่รู้ว่าตัวเองซื้อได้เท่าไร | เกือบทุกคน | พาดูบ้านเกินกำลัง เสียเวลาสองฝ่าย |

**ข้อสังเกตของคนทำมานาน:** ทั้ง 5 ข้อไม่ใช่ปัญหาเรื่อง "ตัวบ้าน" เลยสักข้อเดียว
นายหน้าเกือบทั้งตลาดแข่งกันที่ "มีบ้านสวยกว่า ถูกกว่า" ซึ่งเป็นสนามที่แพ้ง่ายและลอกกันได้
สนามที่ยังว่างคือ **"ใครพาคนกู้ไม่ผ่านให้กู้ผ่านได้"**

### ธีสิส

> เราไม่ใช่ธุรกิจขายบ้าน
> เราคือ **โรงงานผลิตผู้กู้ที่ธนาคารอนุมัติ** ที่บังเอิญมีบ้านของตัวเองไว้ขายให้เขาด้วย

ผลที่ตามมาในเชิงกลยุทธ์:

1. **สินทรัพย์สำคัญที่สุดของบริษัทไม่ใช่บ้าน แต่คือ "ฐานลูกค้าที่กำลังปั้นเครดิตอยู่"**
   บ้านหมุนออกไปทุก 3–6 เดือน แต่ฐานลูกค้ากลุ่ม B/C สะสมขึ้นเรื่อยๆ และคือคนที่จะซื้อบ้านหลังที่ 10, 20, 50 ของเรา
2. **เราซื้อบ้านตามที่ฐานลูกค้าต้องการ ไม่ใช่ซื้อตามที่เราชอบ**
   มีลูกค้ากลุ่ม A รอ 8 คน ที่งบผ่อน 7,000/เดือน ต้องการโซนควนลัง → เราไปหาบ้านแบบนั้น ไม่ใช่ซื้อบ้านสวยราคา 4 ล้านแล้วค่อยหาคนซื้อ
3. **คู่แข่งลอกบ้านสวยของเราได้ใน 1 เดือน แต่ลอกฐานลูกค้า 400 คนที่เราปั้นเครดิตมา 2 ปีไม่ได้**

### สามแหล่งกำไร (อย่าพึ่งแหล่งเดียว)

| # | แหล่งรายได้ | ลักษณะ | ความเสี่ยง | เริ่มเมื่อไร |
|---|---|---|---|---|
| 1 | **ส่วนต่างซื้อ–รีโนเวท–ขาย** (Flip) | กำไรก้อนใหญ่ 15–25% ต่อหลัง | ใช้เงินทุนหนัก เงินจม | เดือนที่ 1 |
| 2 | **ค่านายหน้าฝากขาย** (Brokerage) | 3% ของราคาขาย ไม่ใช้เงินทุน | รายได้ไม่แน่นอน | เดือนที่ 1 (ควบคู่ ทำให้มีรายได้ระหว่างรอหลังแรกเสร็จ) |
| 3 | **บริการปั้นเครดิต / เช่าออม / ผ่อนดาวน์** | รายได้ประจำ + ล็อกลูกค้า | ต้องระวังกฎหมายและจริยธรรม | เดือนที่ 3 |

**กฎเหล็ก:** ห้ามให้แหล่งที่ 1 กินสภาพคล่องจนแหล่งที่ 2–3 ทำไม่ได้ ธุรกิจ flip ที่ตายเกือบทั้งหมดตายเพราะ *เงินจม* ไม่ใช่เพราะ *ขายไม่ได้*

## 1.2 ตลาดหาดใหญ่ — สิ่งที่ต้องรู้ก่อนซื้อหลังแรก

### แรงขับเคลื่อนดีมานด์ในพื้นที่

หาดใหญ่ไม่ใช่เมืองราชการ แต่เป็น **เมืองการค้า–การศึกษา–การแพทย์** ของภาคใต้ตอนล่าง ดีมานด์บ้านมาจาก:

| แหล่งดีมานด์ | ลักษณะผู้ซื้อ | โซนที่เขาต้องการ |
|---|---|---|
| ม.อ. หาดใหญ่ + สถานศึกษา | อาจารย์ บุคลากร เจ้าหน้าที่ | คอหงส์, ทุ่งใหญ่, รอบ ม.อ. |
| รพ.หาดใหญ่ / รพ.สงขลานครินทร์ | พยาบาล เจ้าหน้าที่สาธารณสุข (รายได้ประจำ = กู้ง่าย) | ในเมือง, คอหงส์ |
| ค้าส่ง–ค้าปลีก, ตลาด, ท่องเที่ยวมาเลย์ | ผู้ค้า อาชีพอิสระ (รายได้ดีแต่กู้ยาก) | ในเมือง, คลองแห, ควนลัง |
| นิคม/โรงงาน/ขนส่ง, สนามบิน | พนักงานประจำ | ควนลัง, บ้านพรุ, พะตง, ท่าข้าม |
| ราชการ/รัฐวิสาหกิจ | สวัสดิการสินเชื่อดี = ลูกค้าเกรด A | ทุกโซน |
| คนสงขลา/ปัตตานี/ยะลา/นราธิวาส ย้ายเข้าเมือง | ครอบครัวหนุ่มสาว = กลุ่มเป้าหมายหลักของเรา | รอบเมืองที่ราคาเข้าถึงได้ |

**การบ้านข้อแรกของทีม (สัปดาห์ที่ 1):** ทำตาราง 13 ตำบลของอำเภอหาดใหญ่ (หาดใหญ่, ควนลัง, คูเต่า, คลองแห, คลองอู่ตะเภา, ฉลุง, ทุ่งตำเสา, ทุ่งใหญ่, ท่าข้าม, น้ำน้อย, บ้านพรุ, พะตง, และพื้นที่ต่อเนื่อง) แล้วกรอก 6 คอลัมน์:
`ราคาบ้านมือสอง/ตร.ว. · ค่าเช่าบ้านทั้งหลัง/เดือน · เวลาเข้าเมืองชั่วโมงเร่งด่วน · เกรดน้ำท่วม · จำนวนประกาศขายค้างในตลาด · โรงเรียน/ตลาด/รพ. ที่ใกล้ที่สุด`

จากนั้นเลือก **3 โซนหลัก** ที่จะโฟกัส และห้ามซื้อนอกโซนใน 12 เดือนแรก
เหตุผล: การรู้ราคาลึกใน 3 โซน ทำเงินได้มากกว่ารู้ราคาตื้นใน 13 ตำบล การขยายโซนคือสาเหตุอันดับต้นๆ ที่มือใหม่ซื้อแพง

### เกณฑ์ตัดสินใจ "ค่าเช่าเทียบค่าผ่อน" ในแต่ละโซน

หัวใจของกลุ่มลูกค้าเราคือ *คนที่จ่ายค่าเช่าอยู่แล้ว* ดังนั้นตัวเลขที่สำคัญที่สุดของแต่ละโซนคือ:

```
อัตราส่วนเช่า-ผ่อน = ค่าผ่อนบ้านต่อเดือน ÷ ค่าเช่าบ้านขนาดใกล้เคียงในโซนเดียวกัน
```

- **< 1.2 → โซนทองคำ** — ผ่อนแพงกว่าเช่าไม่ถึง 20% ปิดการขายง่ายมาก ให้เน้นซื้อโซนนี้
- **1.2–1.6 → โซนปกติ** — ขายได้ ต้องใช้การตลาดอธิบาย "จ่ายเพิ่มเดือนละ X ได้กรรมสิทธิ์"
- **> 1.6 → โซนยาก** — ลูกค้ากลุ่มผู้เช่าเข้าไม่ถึง ให้ปล่อยไปหรือขายให้กลุ่มอื่น

ตัวเลขนี้ต้องเก็บจริงจากประกาศเช่าและประกาศขายในโซนเดียวกัน อย่าเดา

## 1.3 เกรดน้ำท่วม — ตัวแปรที่สำคัญที่สุดของหาดใหญ่

หาดใหญ่มีประวัติน้ำท่วมใหญ่ซ้ำหลายรอบ (2543, 2553, และรอบใหญ่ปลายปี 2568) และมีน้ำท่วมขังย่อยแทบทุกฤดูฝน
บ้านสองหลังหน้าตาเหมือนกัน อยู่ห่างกัน 400 เมตร ราคาต่างกันได้ **15–30%** เพราะเรื่องนี้เรื่องเดียว

**คนนอกพื้นที่ประเมินเรื่องนี้ไม่เป็น = โอกาสของเรา**
คนในพื้นที่รู้ แต่ไม่มีใครทำเป็นระบบ = ช่องว่างที่เราเข้าไปยึด

### ระบบเกรดน้ำ (Flood Grade) — ใช้เป็นฟิลด์บังคับในทุกทรัพย์

| เกรด | นิยาม | ผลต่อราคาซื้อ | ผลต่อการขาย |
|---|---|---|---|
| **A** | ไม่เคยมีน้ำเข้าตัวบ้านเลย รวมปี 2553 และ 2568 | ซื้อได้ราคาเต็ม | **ใช้เป็นพาดหัวโฆษณาอันดับหนึ่ง** — มีใบรับรองจากเพื่อนบ้าน + ภาพถ่ายช่วงน้ำท่วมประกอบ |
| **B** | น้ำขังถนน/หน้าบ้าน ไม่เกิน 30 ซม. ไม่เข้าตัวบ้าน | ต่อรองลง 3–5% | ขายได้ปกติ ต้องเปิดเผยตรงๆ พร้อมภาพ |
| **C** | น้ำเข้าตัวบ้าน < 50 ซม. | ต่อรองลง 10–15% | ต้องติด "แพ็กสู้น้ำ" เต็มรูปแบบ + ลดราคาขาย |
| **D** | น้ำเข้าตัวบ้าน 50–150 ซม. | ต่อรองลง 20–30% และต้องเดินระบบไฟใหม่ทั้งหลัง | ขายยาก ธนาคารอาจประเมินต่ำ ควรเลี่ยงในปีแรก |
| **E** | น้ำเข้าเกิน 150 ซม. หรือท่วมซ้ำทุก 2–3 ปี | **ไม่ซื้อ** | — |

### วิธีตรวจเกรดน้ำ (ห้ามข้ามขั้นตอน)

1. **ถามร้านค้าหัวมุมซอย / ร้านชำ / วินมอเตอร์ไซค์** — คนกลุ่มนี้อยู่ที่เดิม 10–20 ปี พูดความจริง และไม่มีส่วนได้เสียกับการขาย
2. **ถามเพื่อนบ้านอย่างน้อย 3 หลัง** คนละทิศ ถามคำถามเดียวกัน: *"ปี 68 น้ำถึงตรงไหนของบ้านครับ"* แล้วให้เขาชี้ระดับด้วยมือ ถ่ายรูปไว้
3. **ดูรอยคราบน้ำจริง** — บนเสารั้ว ผนังนอก ประตูเหล็กม้วน ใต้ถุน ตู้ไฟ คราบน้ำไม่โกหก (ถ้าผนังนอกเพิ่งทาสีใหม่ทั้งที่บ้านเก่า = สัญญาณเตือน)
4. **ค้นกลุ่ม Facebook ชุมชน/หมู่บ้าน ย้อนช่วงน้ำท่วม** — ภาพถ่ายจากชาวบ้านตอนนั้นคือหลักฐานที่ดีที่สุด
5. **ตรวจแผนที่เสี่ยงภัยน้ำท่วมของหน่วยงานรัฐ** ประกอบ (แต่ให้น้ำหนักน้อยกว่าข้อ 1–4 เพราะความละเอียดระดับซอยไม่พอ)
6. **ห้ามเชื่อคำตอบของเจ้าของบ้านเพียงฝ่ายเดียว** และให้เขียนข้อรับรองเรื่องระดับน้ำท่วมลงใน **สัญญาจะซื้อจะขาย** ทุกครั้ง

### เปลี่ยนความเสี่ยงเป็นจุดขาย: แบรนด์ "บ้านสู้น้ำ"

แทนที่จะปิดเรื่องน้ำ เราทำตรงข้าม — **ประกาศเกรดน้ำของทุกหลังอย่างเปิดเผย** และขายมาตรฐาน "แพ็กสู้น้ำ" ที่ติดตั้งให้ทุกหลัง (รายละเอียดสเปกอยู่ใน [02-workflow.md](02-workflow.md) สเตจ S4)

ผลลัพธ์ที่ได้ 3 อย่าง:
- **ความไว้ใจ** — ในตลาดที่ทุกคนปิดข้อมูล คนที่เปิดข้อมูลก่อนคือคนที่ได้ลูกค้า
- **ราคาที่สูงกว่า** — บ้านเกรด A ที่มี "หลักฐานว่าไม่ท่วม" ขายได้แพงกว่าบ้านเกรด A ที่ไม่มีหลักฐาน
- **ปิดความเสี่ยงทางกฎหมาย** — การปกปิดสภาพทรัพย์ที่เป็นสาระสำคัญ เปิดช่องให้ผู้ซื้อฟ้องเพิกถอนสัญญาได้

## 1.4 การแบ่งกลุ่มลูกค้า — แบ่งตาม "ความพร้อมกู้" ไม่ใช่ตามอายุหรือรายได้

นี่คือส่วนที่ทำให้ธุรกิจนี้ต่างจากนายหน้าทั่วไป
นายหน้าทั่วไปแบ่งลูกค้าเป็น "สนใจ / ไม่สนใจ" — เราแบ่งเป็น **A / B / C / D ตามความพร้อมกู้ (Bankability)**

| เกรด | นิยาม | สัดส่วนที่คาด | เวลาปิดการขาย | ทีมที่รับผิดชอบ | สิ่งที่ทำ |
|---|---|---|---|---|---|
| **A — พร้อมกู้ทันที** | DSR เหลือพอ, บูโรสะอาด, มีเอกสารรายได้, มีเงินก้อนวันโอน | 10–15% | 30–60 วัน | Sales Closer | นัดดูบ้านภายใน 72 ชม. ปิดให้เร็วที่สุด |
| **B — แก้ได้ใน 1–6 เดือน** | DSR สูงเกินนิดหน่อย, มีหนี้บัตร/บัตรกดเงินสด, เอกสารรายได้ไม่ครบ, เงินก้อนยังไม่พอ | 30–40% | 3–8 เดือน | Credit Officer + Sales | เข้าโปรแกรมปั้นเครดิต 90 วัน + พาดูบ้านเพื่อสร้างแรงจูงใจ |
| **C — ต้องใช้เวลา 6–24 เดือน** | เคยค้างชำระเกิน 90 วัน, อยู่ระหว่างปิดหนี้, อาชีพอิสระไม่มีเดินบัญชี, หนี้นอกระบบ | 30–40% | 9–24 เดือน | Credit Officer | เข้ากลุ่มดูแลระยะยาว + เสนอเช่าออม/ผ่อนดาวน์ |
| **D — ยังไม่ใช่ลูกค้า** | ไม่มีรายได้ประจำที่พิสูจน์ได้เลย, อยู่ระหว่างถูกฟ้อง/บังคับคดี, ไม่ต้องการซื้อจริง | 15–25% | — | ระบบอัตโนมัติ | ให้ความรู้ฟรี เก็บในลิสต์ ไม่ใช้เวลาเซลส์ **ห้ามไล่** เพราะเขาอาจแนะนำเพื่อนให้เรา |

### ทำไมการแบ่งแบบนี้ถึงสำคัญที่สุด

- **เวลาของเซลส์คือทรัพยากรที่แพงที่สุด** — เซลส์ 1 คนพาดูบ้านได้วันละ 2–3 ราย ถ้าครึ่งหนึ่งเป็นเกรด D ก็เท่ากับเผาเงินทิ้งครึ่งหนึ่ง
- **กลุ่ม B และ C รวมกันคือ 60–80% ของตลาด** และเป็นกลุ่มที่นายหน้าทั่วไปทิ้ง เรามีทั้งสินค้าและระบบไปรับ = ตลาดใหญ่ที่ไม่มีคู่แข่ง
- **การบอกลูกค้าตรงๆ ว่าเขายังกู้ไม่ผ่าน คือการสร้างความไว้ใจ ไม่ใช่การเสียลูกค้า** — เขาจะจำเราในฐานะคนที่ไม่หลอกให้เสียเวลา และจะกลับมาเมื่อพร้อม

### สิ่งที่ห้ามทำเด็ดขาด

- ❌ พาลูกค้าดูบ้านที่เกินกำลังผ่อนของเขา (สร้างความคาดหวังแล้วทำลาย = ลูกค้าหายและพูดต่อในทางลบ)
- ❌ บอกลูกค้าว่า "กู้ผ่านแน่นอน" ก่อนตรวจบูโรและคำนวณ DSR
- ❌ ยัดลูกค้าให้กู้เกินกำลัง เพื่อให้ปิดดีลได้ — ลูกค้าจะกลายเป็น NPL ภายใน 2 ปี และชื่อเสียงเราจะพังทั้งจังหวัด

## 1.5 Buy Box — เกณฑ์ซื้อทรัพย์ (ประกาศให้ทุกคนในทีมและสายข่าวรู้)

Buy Box คือ "หน้าตาของบ้านที่เราซื้อ" เขียนให้ชัดจนคนอื่นหาให้เราได้โดยไม่ต้องถาม

### ✅ ซื้อ

| หัวข้อ | เกณฑ์ |
|---|---|
| ราคาขายเป้าหมาย (ARV) | 1.2 – 2.8 ล้านบาท (จุดที่ผ่อน 6,000–14,000/เดือน = ตรงกับกลุ่มผู้เช่า) |
| ประเภท | บ้านเดี่ยวชั้นเดียว / บ้านแฝด / ทาวน์เฮาส์ 2 ชั้น ในหมู่บ้านจัดสรร หรือบ้านในซอยที่รถเก๋งสวนกันได้ |
| เนื้อที่ | 30 – 80 ตร.ว. |
| อายุบ้าน | 8 – 30 ปี (โครงสร้างยังดี ระบบเก่าที่เปลี่ยนได้ ราคาต่อรองได้) |
| เอกสารสิทธิ์ | **โฉนด (น.ส.4 จ.) เท่านั้น** |
| ทางเข้า-ออก | ติดถนนสาธารณะ หรือมีภาระจำยอม**จดทะเบียนแล้ว** เท่านั้น |
| ระยะทาง | เข้าตัวเมืองหาดใหญ่ ≤ 20 นาที ในชั่วโมงเร่งด่วน |
| เกรดน้ำ | A หรือ B (C ซื้อได้เฉพาะเมื่อส่วนลดถึงเกณฑ์และมีงบแพ็กสู้น้ำครบ) |
| สภาพ | ซ่อมได้ด้วยงบ ≤ 20% ของ ARV |
| ราคาซื้อ | **ต้องต่ำกว่า MAO ที่คำนวณได้** (ดู [05-unit-economics.md](05-unit-economics.md)) |

### ❌ ไม่ซื้อ (ตัดจบทันที ไม่ต้องเสียเวลาต่อรอง)

- โฉนดติดอายัด / ติดคดี / อยู่ระหว่างบังคับคดีที่ยังไม่จบ
- เจ้าของไม่ครบ (มรดกยังไม่แบ่ง, ผู้ถือกรรมสิทธิ์รวมไม่ยินยอมทุกคน, ผู้เยาว์ถือกรรมสิทธิ์)
- มีผู้อยู่อาศัย/ผู้เช่าที่ยังไม่ยอมออก หรือส่งมอบบ้านไม่ว่าง
- ทางเข้าออกเป็น "ทางผ่านที่ดินคนอื่นแบบตกลงปากเปล่า"
- โครงสร้างทรุด/ร้าวแนวเฉียงที่เสา-คาน / เสาเข็มมีปัญหา
- ปลูกสร้างผิดแบบหรือรุกล้ำที่ข้างเคียง/ที่สาธารณะ
- เกรดน้ำ D–E
- ติดเสาไฟฟ้าแรงสูง / สุสาน / โรงงานส่งกลิ่น / ถนนซอยตัน 2 เมตร รถดับเพลิงเข้าไม่ได้
- ประวัติเสียชีวิตในบ้าน — ตลาดภาคใต้อ่อนไหวเรื่องนี้มาก ขายยากและต้องเปิดเผย
- **ไม่มีลูกค้าในฐานข้อมูลของเราที่จะซื้อบ้านแบบนี้ได้** ← ข้อนี้สำคัญที่สุดและมือใหม่ลืมบ่อยที่สุด

### เครื่องมือคัดของภายใน 90 วินาที

ก่อนเสียเวลาไปดู ให้ตอบ 5 ข้อนี้จากภาพถ่ายและข้อมูลที่ได้:

```
1. ราคาขายจริงในโซนนี้เท่าไร (ARV)         → ถ้าไม่รู้ ห้ามไปดู ให้ไปหา comps ก่อน
2. เกรดน้ำเท่าไร                            → D/E ตัดจบ
3. โฉนดสมบูรณ์ เจ้าของครบไหม                → ไม่ครบ ตัดจบ
4. ผ่อนเดือนละเท่าไรถ้าขายราคาเป้า          → เกิน 15,000 ตัดจบ (หลุดกลุ่มเป้าหมาย)
5. มีลูกค้าเกรด A/B ในฐานเราที่เหมาะกี่คน     → 0 คน ให้ชะลอ
```
