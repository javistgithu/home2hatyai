# 05 — ตัวเลขและเศรษฐศาสตร์ต่อหลัง (Unit Economics)

> ⚠️ **ตัวเลขทั้งหมดในเอกสารนี้เป็นสมมติฐานตั้งต้นเพื่อให้เริ่มคำนวณได้ ไม่ใช่ข้อมูลตลาดที่ยืนยันแล้ว**
> อัตราภาษี ค่าธรรมเนียมโอน และมาตรการรัฐเปลี่ยนทุกปี — ต้องยืนยันกับสำนักงานที่ดินอำเภอหาดใหญ่
> สรรพากรพื้นที่ และนักบัญชีของคุณ ก่อนใช้ตัดสินใจจริงทุกครั้ง

---

## 5.1 สูตรหลัก: ราคาซื้อสูงสุดที่ยอมจ่าย (MAO)

**นี่คือสมการเดียวที่ตัดสินว่าธุรกิจนี้กำไรหรือขาดทุน**

```
MAO = ARV − Reno − Holding − Selling − Profit
```

| ตัวแปร | ความหมาย | วิธีหา |
|---|---|---|
| **ARV** | ราคาขายจริงที่คาดได้หลังรีโนเวท | comps ปิดจริง 3 รายการ รัศมี 2 กม. ย้อนหลัง 6 เดือน — **ห้ามใช้ราคาประกาศ** |
| **Reno** | งบรีโนเวท × 1.15 (บวกกันพลาด 15%) | ประมาณจาก checklist ลงพื้นที่ + ใบเสนอราคาช่าง |
| **Holding** | ต้นทุนถือครองต่อเดือน × เดือนที่คาดว่าจะถือ | ดอกเบี้ย + ภาษีที่ดิน + ค่าส่วนกลาง + น้ำ/ไฟ + ประกัน + ค่าดูแล |
| **Selling** | ต้นทุนขายทั้งหมด | ค่าคอม + ค่าโอนส่วนของเรา + ภาษี + งบการตลาด + แพ็กของแถม |
| **Profit** | กำไรขั้นต่ำที่ยอมรับ = ARV × 18% | ถ้าไม่ถึง 18% ไม่คุ้มความเสี่ยงของธุรกิจนี้ |

### ตัวอย่างการคำนวณเต็ม (ตัวเลขสมมติ — ใช้เป็นแบบฝึก ไม่ใช่ข้อมูลจริง)

```
บ้านเดี่ยวชั้นเดียว 3 นอน 2 น้ำ · 52 ตร.ว. · อายุ 18 ปี · เกรดน้ำ B · ต.ควนลัง

ARV (จาก comps ปิดจริง 3 หลัง)                       1,590,000
─────────────────────────────────────────────────────────────
หัก  งานรีโนเวท Level 2                    145,000
     แพ็กสู้น้ำ                             65,000
     แพ็กพร้อมอยู่ (แอร์ ผ้าม่าน ครัว ฯลฯ)  110,000
     รวมงานทั้งหมด            320,000
     บวกกันพลาด 15%            48,000
     Reno รวม                                        368,000
─────────────────────────────────────────────────────────────
หัก  ถือครอง 5 เดือน × 9,000/เดือน
     (ดอกเบี้ย + ภาษีที่ดิน + น้ำไฟ + ประกัน + ดูแล)   45,000
─────────────────────────────────────────────────────────────
หัก  ต้นทุนขาย
     ค่าคอม co-broke 2%                     31,800
     ค่าโอนส่วนของเรา + ภาษีตอนขาย          65,000
     งบการตลาด 1.5% ของ ARV                 23,850
     รวม                                             120,650
─────────────────────────────────────────────────────────────
หัก  กำไรเป้าหมาย 18% ของ ARV                        286,200
─────────────────────────────────────────────────────────────
      MAO = ราคาซื้อสูงสุดที่ยอมจ่าย                  770,150
```

**การอ่านผลลัพธ์:**
- เจ้าของขอ **750,000** → ✅ ซื้อได้ (ต่ำกว่า MAO 20,150 = ได้กำไรเกินเป้าเล็กน้อย)
- เจ้าของขอ **850,000** → ⚠️ เกิน MAO 80,000 → ต่อรองลง หรือทิ้ง
- เจ้าของขอ **950,000** → ❌ ห่างเกินไป ไม่ต้องเสียเวลาไปดู

> **บทเรียนสำคัญที่สุดในเอกสารทั้งชุด:**
> คนทำธุรกิจนี้ที่เจ๊ง ไม่ได้เจ๊งเพราะขายไม่ได้ แต่เจ๊งเพราะ **"รู้สึกว่ามันน่าจะได้"** แล้วซื้อเกิน MAO
> ทุกครั้งที่คุณคิดว่า *"เกินไปนิดเดียว น่าจะยังพอมีกำไร"* — นั่นคือกำไรทั้งดีลที่กำลังจะหายไป
> ทำตารางนี้ให้เสร็จ **ก่อน** เจอเจ้าของ ไม่ใช่หลังจากที่คุณตกหลุมรักบ้านหลังนั้นแล้ว

## 5.2 โครงสร้างต้นทุนที่ต้องรู้ (ตามกฎหมายไทย)

### ต้นทุนตอนซื้อ

| รายการ | ฐานคำนวณ | ปกติใครจ่าย |
|---|---|---|
| ค่าธรรมเนียมการโอนกรรมสิทธิ์ | % ของราคาประเมินราชการ | ตกลงกัน (มักคนละครึ่ง) |
| ค่าอากรแสตมป์ / ภาษีธุรกิจเฉพาะ | % ของราคาซื้อขายหรือราคาประเมิน แล้วแต่สูงกว่า | ผู้ขาย |
| ภาษีเงินได้หัก ณ ที่จ่าย | ตามหลักเกณฑ์กรมสรรพากร | ผู้ขาย |
| ค่าคำขอ/ค่าพยาน/ค่าอากร | จำนวนเล็กน้อย | ตกลงกัน |
| ค่าทนาย/ค่าดำเนินการ | ตามตกลง | ผู้ซื้อ |

### ⚠️ ภาษีตอนขาย — จุดที่กินกำไรมากที่สุดและมือใหม่ไม่รู้

การขายอสังหาริมทรัพย์**ภายในระยะเวลาที่กฎหมายกำหนด**หลังได้มา ต้องเสีย **ภาษีธุรกิจเฉพาะ**
ซึ่งมีอัตรารวมสูงกว่าอากรแสตมป์อย่างมีนัยสำคัญ (ต่างกันหลายเท่า)

มีเงื่อนไขข้อยกเว้นบางประการตามกฎหมาย เช่น การถือครองครบระยะเวลาที่กำหนด
หรือการมีชื่ออยู่ในทะเบียนบ้านครบระยะเวลาที่กำหนด ซึ่งจะเสียอากรแสตมป์แทน

**ผลต่อกลยุทธ์ — มีทางเลือกที่ต้องชั่งน้ำหนัก:**

| กลยุทธ์ | ภาษี | เงินจม | จำนวนรอบ/ปี | เหมาะกับ |
|---|---|---|---|---|
| **ขายเร็ว (Flip)** | สูงกว่า | ต่ำ | 2–3 รอบ | เงินทุนจำกัด ต้องการหมุนเร็ว ← **แนะนำสำหรับปีแรก** |
| **ถือครองให้ครบเงื่อนไข** | ต่ำกว่า | สูง | < 1 รอบ | เงินทุนหนา ทำควบคู่กับปล่อยเช่าระหว่างถือ |

> **คำแนะนำ:** ปีแรกให้เลือกขายเร็ว **การหมุนเงินได้ 2–3 รอบต่อปี ให้ผลตอบแทนรวมต่อปีสูงกว่าการประหยัดภาษีจากการถือครองยาว**
> แต่ **ต้องคำนวณภาษีที่สูงกว่านั้นเข้าไปในสูตร MAO ตั้งแต่แรก** ไม่ใช่ไปเซอร์ไพรส์ตอนวันโอน
>
> ⚠️ อัตรา เงื่อนไข และข้อยกเว้นทั้งหมดต้องยืนยันกับ**นักบัญชีหรือสรรพากรพื้นที่** ก่อนวางแผน
> อย่าใช้ข้อมูลจากเอกสารนี้หรือจากอินเทอร์เน็ตเป็นฐานการตัดสินใจทางภาษี

### ต้นทุนถือครองรายเดือน (ประมาณการ)

| รายการ | ประมาณการ/เดือน | หมายเหตุ |
|---|---|---|
| ดอกเบี้ยเงินกู้ (ถ้ากู้มาซื้อ) | ตามวงเงินและอัตรา | ก้อนใหญ่ที่สุด |
| ภาษีที่ดินและสิ่งปลูกสร้าง | เฉลี่ยรายเดือน | อัตราต่างกันตามการใช้ประโยชน์ — บ้านที่ไม่มีคนอยู่อาจเข้าข่ายอัตราอื่น **ตรวจกับ อบต./เทศบาล** |
| ค่าส่วนกลาง (ถ้าอยู่ในหมู่บ้านจัดสรร) | ตามหมู่บ้าน | |
| ค่าน้ำ–ไฟขั้นต่ำ | 300–800 | ต้องเปิดไว้เพื่อพาลูกค้าชม |
| ประกันอัคคีภัย | เฉลี่ยรายเดือน | |
| ค่าดูแล/ทำความสะอาด/ตัดหญ้า | 1,000–2,000 | บ้านรกขายไม่ได้ |

> **ต้นทุนถือครองคือศัตรูเงียบ** บ้านที่ขายช้ากว่าแผน 3 เดือน = เสียกำไรไปหลายหมื่น
> นี่คือเหตุผลที่ **DOM (วันขายเฉลี่ย) เป็น KPI ที่สำคัญพอๆ กับกำไรต่อหลัง**

## 5.4 เกณฑ์ตัวเลขที่ยอมรับได้ (ตั้งไว้ก่อน แล้วปรับตามข้อมูลจริง)

| ตัวชี้วัด | เกณฑ์ขั้นต่ำ | เป้าหมาย | ถ้าต่ำกว่าเกณฑ์ |
|---|---|---|---|
| กำไรขั้นต้น (% ของราคาขาย) | 15% | 18–25% | ทบทวนราคาซื้อและงบรีโนเวท |
| งบรีโนเวท (% ของ ARV) | ≤ 22% | 8–15% | สเปกเกินความจำเป็น |
| ต้นทุนถือครองรวม (% ของ ARV) | ≤ 4% | ≤ 2.5% | ขายช้าเกินไป → ปัญหาอยู่ที่ราคาหรือการตลาด |
| DOM (วันขายนับจากพร้อมขาย) | ≤ 120 วัน | ≤ 90 วัน | ลดราคาตามกฎ 45/90 วัน |
| รอบเงินทุน (ซื้อ→ขาย) | ≤ 240 วัน | ≤ 180 วัน | |
| จำนวนรอบต่อปี | ≥ 1.5 | 2–3 | |
| อัตราอนุมัติสินเชื่อของลูกค้าเรา | ≥ 55% | ≥ 70% | คัดกรองต้นทางหลวมเกินไป |

## 5.5 การจัดการสภาพคล่อง (ส่วนที่ทำให้ธุรกิจนี้ตายมากที่สุด)

### กฎเหล็ก 5 ข้อ

1. **ปีแรก ถือบ้านพร้อมกันไม่เกิน 2–3 หลัง** ไม่ว่าจะเจอดีลดีแค่ไหน
   ดีลดีมีเสมอ แต่เงินสดหมดแล้วหมดเลย
2. **มีเงินสำรอง 6 เดือนของค่าใช้จ่ายคงที่ แตะต้องไม่ได้** ไม่ว่ากรณีใด
3. **ตั้งเพดานเวลาถือครอง 180 วัน** — ครบแล้วตัดขายที่ราคาที่ขายได้
   ขาดทุนหนึ่งหลังกู้คืนได้ เงินจมทั้งพอร์ตกู้คืนไม่ได้
4. **อย่ากู้เต็มวงเงิน** — เผื่อพื้นที่ไว้สำหรับเหตุไม่คาดฝัน (งานบานปลาย ช่างทิ้งงาน น้ำท่วม ตลาดชะลอ)
5. **แยกบัญชีให้เด็ดขาด** — เงินซื้อทรัพย์ / เงินดำเนินงาน / เงินสำรอง
   การปนบัญชีทำให้มองไม่เห็นว่ากำลังจะไม่มีเงินจ่ายช่างเดือนหน้า

### สัญญาณอันตราย 5 ข้อ — เจอข้อใดข้อหนึ่ง ให้หยุดซื้อทันที

- 🚩 มีบ้านที่ขายเกิน 120 วันมากกว่า 1 หลัง
- 🚩 ต้องใช้เงินจากดีลถัดไปมาจ่ายค่าช่างของดีลปัจจุบัน
- 🚩 เงินสำรองต่ำกว่า 3 เดือน
- 🚩 งบรีโนเวทเกินแผนเกิน 20% ติดกัน 2 หลัง
- 🚩 ลูกค้าที่พาไปยื่นกู้ ไม่ผ่านติดกัน 5 ราย ← สัญญาณว่าคัดกรองต้นทางผิด ไม่ใช่ปัญหาธนาคาร

## 5.6 การหา ARV ให้แม่น — วิธีปฏิบัติ

### เลือก comps อย่างไร

| เกณฑ์ | มาตรฐาน |
|---|---|
| ระยะทาง | ≤ 2 กม. และควรอยู่ในโซนน้ำท่วมระดับเดียวกัน |
| เวลา | ปิดขายภายใน 6 เดือนล่าสุด |
| ประเภท | บ้านลักษณะเดียวกัน (เดี่ยว/แฝด/ทาวน์เฮาส์) |
| ขนาด | เนื้อที่ต่างกันไม่เกิน ±25% |
| อายุ | ต่างกันไม่เกิน ±10 ปี |
| **ราคา** | **ราคาปิดขายจริงเท่านั้น** |

### ปรับค่า comps

```
ARV = ราคา comp
      ± ปรับตามเนื้อที่ดินที่ต่างกัน (× ราคาต่อ ตร.ว. ของโซน)
      ± ปรับตามพื้นที่ใช้สอยที่ต่างกัน
      ± ปรับตามอายุและสภาพ
      ± ปรับตามเกรดน้ำ (A สูงกว่า B ประมาณ 3–5% · B สูงกว่า C ประมาณ 8–12%)
      ± ปรับตามทำเลย่อย (ติดถนนใหญ่ / ในซอย / ซอยตัน / ใกล้ตลาด)
```
ทำ 3 comps แล้วใช้ **ค่ากลาง ไม่ใช่ค่าสูงสุด** ← มือใหม่มักเผลอใช้ค่าสูงสุดเพราะอยากให้ดีลผ่าน

### วิธีหาราคาปิดขายจริงในหาดใหญ่

1. **เจ้าหน้าที่สินเชื่อที่รู้จัก** — เขาเห็นราคาประเมินและราคาซื้อขายจริงทุกวัน (ถามเป็นภาพรวม ไม่ใช่ข้อมูลรายบุคคล)
2. **นายหน้าท้องถิ่นที่แลกข้อมูลกัน** — สร้างกลุ่มแลกเปลี่ยนราคาปิดจริง ให้ก่อนแล้วจะได้รับ
3. **ราคาประเมินกรมธนารักษ์** — ใช้เป็น *พื้น* ไม่ใช่ราคาตลาด
4. **ตามดูประกาศที่หายไปจากตลาด** แล้วโทรถามว่าปิดที่เท่าไร (หลายคนบอก)
5. **สร้างฐานข้อมูลของตัวเอง** — บันทึกทุกดีลที่รู้ลงแท็บ `comps` ของ Sheet
   หลังจาก 12 เดือน คุณจะมีฐานข้อมูลที่ **ไม่มีคู่แข่งรายไหนในหาดใหญ่มี** และนั่นคืออำนาจต่อรองที่แท้จริง
