# 02 — Workflow หลัก 9 สเตจ (เอกสารปฏิบัติการ)

> เอกสารนี้คือ "สายพานการผลิต" ของธุรกิจ ทุกหลังและทุกลูกค้าต้องเดินผ่านสเตจเหล่านี้ตามลำดับ
> ทุกสเตจมี **เจ้าของงาน (Owner) · เวลามาตรฐาน (SLA) · เกณฑ์ผ่านเข้าสเตจถัดไป (Gate) · ตัวชี้วัด (KPI)**
> ห้ามข้ามสเตจ ห้ามให้ทรัพย์หรือลูกค้าอยู่ในสเตจใดโดยไม่มี "นัดถัดไป" ระบุวันที่ชัดเจน

---

## แผนผังภาพรวม

```
        สายทรัพย์ (Supply)                          สายลูกค้า (Demand)
  ┌───────────────────────────────┐      ┌──────────────────────────────────┐
  │ S1 หาของ (Sourcing)           │      │ S5 การตลาด + ประกาศขาย           │
  │ S2 คัดดีล + คำนวณ (Underwrite)│──┐   │ S6 รับลูกค้า + คัดเกรด A/B/C/D   │
  │ S3 ซื้อ + นิติกรรม            │  │   │ S7 ปั้นเครดิต + ยื่นกู้           │
  │ S4 รีโนเวท + แพ็กสู้น้ำ       │──┴──▶│ S8 ปิดการขาย + โอน               │
  └───────────────────────────────┘      │ S9 หลังการขาย + บอกต่อ            │
                                          └──────────────┬───────────────────┘
                                                         │
                    ป้อนกลับ: ลูกค้าเกรด B/C ที่ยังไม่พร้อม
                    และข้อมูลความต้องการจริง → กลับไปกำหนด S1
```

**หลักการเชื่อมสองสาย:** สายลูกค้าต้องนำหน้าสายทรัพย์เสมอ
เราต้องมีลูกค้าเกรด A/B ที่ตรงสเปกอย่างน้อย **5 คนต่อบ้าน 1 หลัง** ก่อนกดซื้อ ไม่ใช่ซื้อก่อนแล้วค่อยหาคน

# S1 — หาของ (Sourcing)

**Owner:** เจ้าของ + Sourcing Scout · **SLA:** ป้อนทรัพย์เข้าท่อ ≥ 20 รายการ/เดือน · **KPI:** ต้นทุนต่อดีลที่ปิดได้, สัดส่วนทรัพย์ที่มาจากช่องทางไม่มีคู่แข่ง

## 1.1 ช่องทางหาของ เรียงตามส่วนต่างที่ได้

## 1.2 ระบบสายข่าว (Bird-dog Network) — สร้างอย่างไร

1. ทำ **นามบัตร/การ์ดใบเดียว** เขียน Buy Box สั้นๆ + เบอร์ + QR LINE OA
   ตัวอย่างข้อความ: *"รับซื้อบ้านมือสองหาดใหญ่ 1–3 ล้าน จ่ายเงินสด ปิดเร็วใน 30 วัน แนะนำแล้วปิดได้ รับค่าแนะนำ 10,000 บาท"*
2. แจกให้ 100 คนแรกใน 3 โซนเป้าหมาย: ร้านวัสดุก่อสร้าง, ร้านชำ, วิน, ช่างแอร์/ประปา/ไฟฟ้า, ร้านซ่อมรถ, ร้านกาแฟ, นิติบุคคลหมู่บ้าน, เจ้าหน้าที่สินเชื่อ (เขารู้ว่าใครกำลังจะผ่อนไม่ไหว)
3. เก็บรายชื่อลง Sheet แท็บ `sourcing_pipeline` + ทักทายทุก 30 วัน
4. **จ่ายทันทีที่ปิดดีล ไม่บิดพลิ้ว ไม่ต่อรอง** — ชื่อเสียงเรื่องนี้กระจายในตลาดเร็วกว่าอย่างอื่นทั้งหมด

# S2 — คัดดีล + คำนวณ (Underwriting)

**Owner:** เจ้าของ (คนเดียวที่อนุมัติซื้อได้) · **SLA:** ตัดสินใจภายใน 48 ชม. หลังดูของ · **KPI:** อัตราดีลที่ซื้อแล้วกำไรตรงตามที่คำนวณ ≥ 80%

## 2.1 ลำดับการคำนวณ (ห้ามลัด)

```
ขั้น 1  ARV      = ราคาขายจริงที่คาดได้หลังรีโนเวท  (จาก comps ที่ปิดจริง 3 รายการ ไม่ใช่ราคาประกาศ)
ขั้น 2  Reno     = ประเมินงบรีโนเวทจาก checklist × 1.15 (บวกกันพลาด 15%)
ขั้น 3  Holding  = (ดอกเบี้ย + ภาษีที่ดิน + ค่าส่วนกลาง + น้ำ/ไฟ/ประกัน) × เดือนที่คาดว่าจะถือ
ขั้น 4  Selling  = ค่าคอม + ค่าโอนส่วนของเรา + ภาษี + ค่าการตลาด + แพ็กของแถม
ขั้น 5  Profit   = ARV × 18%   (กำไรขั้นต่ำที่ยอมรับได้)
ขั้น 6  MAO      = ARV − Reno − Holding − Selling − Profit    ← ราคาสูงสุดที่ยอมจ่าย
```

**กฎเหล็กของการหา ARV:** ใช้เฉพาะ **ราคาปิดขายจริง** เท่านั้น
ราคาประกาศในตลาดไทยสูงกว่าราคาปิดจริงประมาณ 8–15% ถ้าใช้ราคาประกาศเป็นฐาน คุณจะซื้อแพงทุกหลังโดยไม่รู้ตัว
วิธีหาราคาปิดจริง: ถามเจ้าหน้าที่สินเชื่อที่รู้จัก, ถามนายหน้าในพื้นที่ที่แลกข้อมูลกัน, ดูราคาประเมินกรมธนารักษ์เป็นพื้น, ตามดูประกาศที่หายไปจากตลาดแล้วโทรถาม

## 2.2 ใบให้คะแนนดีล (100 คะแนน)

| หมวด | เต็ม | เกณฑ์ |
|---|---|---|
| ส่วนต่างราคา (ราคาที่ต่อได้ ต่ำกว่า MAO เท่าไร) | 30 | ต่ำกว่า MAO ≥10% = 30 · 5–10% = 20 · 0–5% = 10 · เกิน MAO = 0 |
| เกรดน้ำ | 20 | A=20 · B=15 · C=7 · D/E=0 |
| ทำเล + ระยะทางเข้าเมือง | 15 | ≤10 นาที=15 · ≤20 นาที=10 · >20 นาที=3 |
| ความง่ายของงานรีโนเวท | 10 | Level 1=10 · Level 2=7 · Level 3=3 |
| ความสะอาดของเอกสารสิทธิ์ | 10 | ครบสมบูรณ์=10 · ต้องแก้ไข=4 · มีปัญหา=0 |
| มีลูกค้าเกรด A/B ในฐานที่ตรงสเปก | 10 | ≥5 คน=10 · 2–4 คน=6 · 0–1 คน=0 |
| ความเร็วในการปิดของผู้ขาย | 5 | พร้อมโอนใน 30 วัน=5 · 60 วัน=3 · ไม่แน่นอน=0 |

**การตัดสิน:** ≥70 ซื้อ · 55–69 กลับไปต่อรองราคาใหม่ · <55 ทิ้ง อย่าเสียดาย

## 2.3 สวิตช์ตัดจบ (Kill Switch) — เจอข้อใดข้อหนึ่ง หยุดทันที

- โฉนดติดอายัด / มีคดีความ / ผู้ถือกรรมสิทธิ์ไม่ครบ
- เกรดน้ำ D–E
- มีผู้อยู่อาศัยที่ยังไม่ยอมย้ายออก และผู้ขายไม่รับรองการส่งมอบบ้านว่าง
- โครงสร้างมีปัญหาที่ต้องเสริมฐานราก
- ราคาต่อรองไม่ลงมาถึง MAO
- ผู้ขายเร่งรัดผิดปกติ / ไม่ยอมให้ตรวจโฉนด / ขอเงินสดนอกสัญญา

## 2.4 ศิลปะการต่อรอง (สำหรับดีลที่ผ่านคะแนน)

- **ยื่นข้อเสนอเป็นหนังสือเสมอ** พร้อมเหตุผลประกอบเป็นข้อๆ (ค่าซ่อมหลังคา X, เดินไฟใหม่ Y, เกรดน้ำ C ลด Z) — ตัวเลขที่มีที่มาต่อรองง่ายกว่าการขอลดลอยๆ
- **ขายเงื่อนไข ไม่ใช่ขอลดราคาอย่างเดียว** — ผู้ขายหลายรายต้องการ *ความเร็วและความแน่นอน* มากกว่าราคาสูงสุด
  ข้อเสนอที่ทรงพลัง: *"ผมให้ราคานี้ แต่จ่ายมัดจำวันนี้ โอนใน 30 วัน ไม่ติดเงื่อนไขกู้ ไม่ขอลดทีหลัง และให้คุณอยู่ต่อฟรี 15 วันหลังโอน"*
- **เงียบเป็น** — ยื่นข้อเสนอแล้วหยุดพูด คนที่พูดต่อคือคนที่เสียเปรียบ
- **มีดีลอื่นเสมอ** — คนที่ต่อรองได้ดีที่สุดคือคนที่เดินจากดีลนี้ได้จริง ห้ามผูกใจกับบ้านหลังใดหลังหนึ่ง

# S4 — รีโนเวท (Renovation)

**Owner:** Reno PM · **SLA:** Level 1 ≤30 วัน · Level 2 ≤60 วัน · Level 3 ≤120 วัน · **KPI:** เสร็จตรงเวลา ≥80%, ไม่เกินงบ ≥85%

## 4.1 หลักคิดเรื่องงบรีโนเวท (สำคัญกว่าเรื่องดีไซน์)

> **ทำเฉพาะ 3 อย่างนี้เท่านั้น:**
> 1. สิ่งที่ **ลูกค้าเห็นแล้วยอมจ่ายเพิ่ม** (ครัว ห้องน้ำ สี พื้น หน้าบ้าน)
> 2. สิ่งที่ **ธนาคารประเมินแล้วให้ราคา** (พื้นที่ใช้สอย โครงสร้าง สภาพโดยรวม)
> 3. สิ่งที่ **เกี่ยวกับความปลอดภัยและความเสี่ยง** (ไฟฟ้า โครงสร้าง น้ำท่วม ปลวก)
>
> **ห้ามรีโนเวทตามรสนิยมตัวเอง** — ทุกบาทที่ใช้เกินสามข้อนี้คือกำไรที่หายไป

**ลำดับผลตอบแทนต่อบาทที่ลงทุน (สูง→ต่ำ) สำหรับกลุ่มลูกค้านี้:**
`ทาสีใหม่ทั้งหลัง > ครัว > ห้องน้ำ > พื้น > หน้าบ้าน/รั้ว > ไฟส่องสว่าง > ต่อเติม`

## 4.2 สเปกมาตรฐาน 3 ระดับ

| ระดับ | งบ (% ของ ARV) | เวลา | ขอบเขตงาน |
|---|---|---|---|
| **L1 — แต่งหน้า** | 3–6% | 21–30 วัน | ล้างบ้านลึก · ทาสีใหม่ทั้งหลังทั้งใน-นอก · เปลี่ยนสวิตช์/ปลั๊ก/หลอดไฟทั้งหมด · ล้าง+ซ่อมแอร์ · ขัด/เคลือบพื้นเดิม · เปลี่ยนก๊อก+ฝักบัว+ชักโครก · จัดสวนหน้าบ้าน · ซ่อมรั้ว/ประตู |
| **L2 — รีโนเวทมาตรฐาน** | 8–12% | 45–60 วัน | ทุกอย่างใน L1 + ครัวบิลท์อินใหม่ + ห้องน้ำใหม่ 1 ห้องทั้งห้อง + ปูกระเบื้อง/SPC ใหม่ชั้นล่าง + ซ่อมหลังคา/ฝ้าที่รั่ว + เดินไฟใหม่บางส่วน + เปลี่ยนวงกบ/ประตูที่ผุ |
| **L3 — ยกเครื่อง** | 15–22% | 75–120 วัน | ทุกอย่างใน L2 + เดินระบบไฟและประปาใหม่ทั้งหลัง + ห้องน้ำใหม่ 2 ห้อง + เปลี่ยนหลังคาทั้งผืน + ทุบผนังเปิดพื้นที่ + ต่อเติมครัวหลังบ้าน + กำจัดปลวกทั้งระบบ |

## 4.3 ⭐ แพ็กสู้น้ำ (Flood-Ready Pack) — จุดขายเฉพาะของหาดใหญ่

ติดตั้งกับ **ทุกหลัง** ไม่ว่าเกรดน้ำใด (เกรด A ก็ทำ เพื่อให้เป็นมาตรฐานแบรนด์) งบประมาณ 40,000–90,000 บาท/หลัง

| รายการ | สเปก | เหตุผล |
|---|---|---|
| ยกเต้ารับ/ปลั๊กชั้นล่าง | สูง **1.20 ม.** จากพื้น (มาตรฐานทั่วไปอยู่ที่ 0.30 ม.) | น้ำ 50 ซม. ไม่ทำให้ไฟช็อตและไม่ต้องรื้อผนัง |
| ตู้คอนซูเมอร์ + มิเตอร์ | ยกสูง ≥1.60 ม. แยกเบรกเกอร์ชั้นล่าง/ชั้นบน | ตัดไฟชั้นล่างได้โดยชั้นบนยังใช้ได้ |
| พื้นชั้นล่าง | กระเบื้อง หรือ SPC กันน้ำ — **ห้ามลามิเนต ห้ามพรม ห้ามปาร์เกต์** | ลามิเนตโดนน้ำครั้งเดียวบวมทิ้งทั้งบ้าน |
| ประตู/วงกบชั้นล่าง | UPVC หรืออลูมิเนียม | ไม้บวม บิด ปิดไม่ได้หลังน้ำลด |
| เฟอร์นิเจอร์บิลท์อิน | ยกลอยจากพื้น 20–30 ซม. หรือใช้โครงเหล็ก/ปูน | ตู้ไม้ติดพื้นเสียหายถาวร |
| คอมเพรสเซอร์แอร์ | ยกแท่นสูง ≥1.50 ม. | คอมจมน้ำ = เปลี่ยนใหม่ 15,000–25,000 |
| ปั๊มน้ำ + ถังเก็บน้ำ | ยกแท่นสูง | มีน้ำใช้ระหว่างน้ำท่วม |
| ที่เก็บของหนีน้ำ | ชั้นลอย/ช่องเก็บของเหนือฝ้า หรือชั้นสูงในห้องนอน | ลูกค้าเข้าใจทันทีว่ามีไว้ทำอะไร |
| วาล์วกันน้ำย้อน | one-way valve ที่ท่อระบายน้ำ/ท่อส้วม | กันน้ำเน่าย้อนขึ้นมาทางท่อ (ปัญหาที่คนมองข้าม) |
| แผงกั้นน้ำหน้าประตู | 1 ชุดถอดได้ **แถมให้ลูกค้า** | ของแถมที่มีมูลค่าทางอารมณ์สูงมากในหาดใหญ่ |
| รางระบายน้ำรอบบ้าน | ลอกท่อ + เพิ่มรางระบาย | ลดน้ำขังรอบบ้าน |

**ผลลัพธ์:** ต้นทุนเพิ่ม 40,000–90,000 แต่ตั้งราคาเพิ่มได้ 3–5% ของ ARV และที่สำคัญกว่าคือ **ลดเวลาขาย (DOM) อย่างมีนัยสำคัญ** เพราะตอบข้อกังวลอันดับหนึ่งของผู้ซื้อในพื้นที่ได้ทั้งหมด

## 4.4 ⭐ แพ็ก "พร้อมอยู่ กระเป๋าใบเดียว" — อาวุธปิดการขายสำหรับกลุ่มผู้เช่า

ลูกค้ากลุ่มนี้ **หมดเงินไปกับเงินดาวน์และค่าโอนแล้ว** ไม่เหลือเงินซื้อแอร์ ผ้าม่าน เตียง
บ้านที่ "ย้ายเข้าอยู่ได้เลย" ปิดการขายได้เร็วกว่าบ้านเปล่าราคาเท่ากันอย่างชัดเจน

| รายการ | หมายเหตุ |
|---|---|
| แอร์ 2 ตัว (ห้องนอนใหญ่ + ห้องนั่งเล่น) | ติดตั้งพร้อมใช้ |
| เครื่องทำน้ำอุ่น ทุกห้องน้ำ | ต้นทุนต่ำ แต่ลูกค้าให้ค่าสูง |
| ผ้าม่าน + มุ้งลวดครบทุกช่อง | สิ่งที่คนลืมคิดว่าต้องจ่ายเพิ่ม 20,000–30,000 |
| ครัวบิลท์อิน + ซิงก์ + เตา | ทำให้บ้านดู "เสร็จ" |
| ถังเก็บน้ำ + ปั๊มน้ำ (ยกสูง) | จำเป็นในหลายโซน |
| ตู้เสื้อผ้าบิลท์อิน 1 ชุด | เพิ่มความรู้สึกคุ้ม |
| ประกันอัคคีภัยปีแรก | ของแถมที่แบงก์บังคับอยู่แล้ว = ลดภาระวันโอนของลูกค้า |

ต้นทุนรวม 80,000–150,000 บาท — ใส่เข้าไปในราคาขายและใช้เป็นจุดขายหลักในโฆษณา
**ข้อความที่ใช้:** *"ย้ายเข้าอยู่ได้เลยด้วยกระเป๋าเสื้อผ้าใบเดียว ไม่ต้องซื้อแอร์ ไม่ต้องซื้อผ้าม่าน ไม่ต้องทำครัวเพิ่ม"*

รายละเอียดเต็มอยู่ใน [04-marketing-and-scripts.md](04-marketing-and-scripts.md) — สรุปขั้นตอนปฏิบัติที่นี่

## 5.1 ชุดสินทรัพย์ประกาศ (ทำครบทุกหลัง ไม่มีข้อยกเว้น)

- [ ] **"การ์ดตัวเลข"** — ภาพเดียวที่ตอบทุกคำถามสำคัญ: `ราคา · ผ่อนเดือนละ · เงินสดที่ต้องมีวันโอน · เกรดน้ำ · ระยะทางถึง ม.อ./ตัวเมือง · จำนวนห้องนอน-น้ำ · เนื้อที่`
  ← **ภาพนี้สำคัญที่สุดในทั้งชุด** เพราะกลุ่มเป้าหมายคำนวณไม่เป็นและไม่กล้าถาม
- [ ] รูป After 25–35 ใบ เรียงตามลำดับการเดินชมบ้าน
- [ ] วิดีโอพาชมแนวตั้ง 60–90 วิ + วิดีโอ Before/After 30 วิ
- [ ] ผังพื้น + ทัวร์ 360°
- [ ] ป้ายหน้าบ้าน + **QR code ไป LINE OA** (ป้ายยังได้ผลสูงมากในต่างจังหวัด)
- [ ] ข้อความประกาศมาตรฐาน 3 ความยาว (สั้น/กลาง/ยาว) สำหรับแต่ละแพลตฟอร์ม

## 5.2 ช่องทางกระจาย (ขึ้นพร้อมกันทุกช่อง)

| ช่องทาง | สิ่งที่ลง | ความถี่ |
|---|---|---|
| Facebook เพจหลัก | โพสต์เปิดตัว + วิดีโอ + อัลบั้มรูป | เปิดตัว 1 + ตาม 2 ครั้ง/สัปดาห์ |
| กลุ่ม Facebook ซื้อขายบ้านหาดใหญ่/สงขลา | ตามกติกาแต่ละกลุ่ม (อ่านกฎก่อน อย่าโดนแบน) | 2–3 กลุ่ม/วัน หมุนเวียน |
| Facebook Marketplace | ลงแยกรายหลัง | ต่ออายุทุก 7 วัน |
| TikTok / Reels / Shorts | วิดีโอพาชม + Before/After + คอนเทนต์ความรู้ | 3–5 คลิป/สัปดาห์ |
| **LINE OA** (ระบบที่มีอยู่แล้ว) | Broadcast แจ้งบ้านใหม่ + Rich Menu + บอทตอบ | ทุกครั้งที่มีบ้านใหม่ |
| เว็บไซต์ (Next.js ในโปรเจกต์นี้) | หน้า listing ต่อหลัง เพื่อ SEO คำว่า "บ้านมือสองหาดใหญ่" | ทุกหลัง |
| Google Business Profile | รูป + โพสต์ + รีวิวลูกค้า | สัปดาห์ละครั้ง |
| เว็บประกาศ (Kaidee, Livinginsider, DDproperty, Baania) | ลงครบทุกเว็บ | ต่ออายุทุกสัปดาห์ |
| **เครือข่ายนายหน้า (Co-broke)** | ส่งชุดข้อมูลให้นายหน้าในพื้นที่ จ่ายคอม 1.5–3% ถ้าพาปิดได้ | ทุกหลัง |

> **Co-broke คือการเพิ่มกำลังขายโดยไม่เพิ่มต้นทุนคงที่** นายหน้าท้องถิ่น 20 คนที่รู้ว่าเรามีบ้านอะไร = ทีมขาย 20 คนที่จ่ายเมื่อสำเร็จเท่านั้น อย่าหวงคอม

## 5.3 กฎการตั้งราคาและลดราคา

- ตั้งราคาเปิดสูงกว่าราคาเป้า **ไม่เกิน 5%** (ตั้งสูงเกินไป = ไม่มีคนดู = เสียโมเมนตัม 2 สัปดาห์แรกที่มีค่าที่สุด)
- **กฎ 14 วัน:** ถ้าใน 14 วันแรกมีคนสอบถาม < 10 ราย → ปัญหาอยู่ที่ *ราคาหรือรูป* ไม่ใช่ที่ตัวบ้าน แก้ทันที
- **กฎ 45 วัน:** ยังไม่มีใครยื่นข้อเสนอ → ลดราคา 3% หรือเพิ่มของแถม
- **กฎ 90 วัน:** ทบทวนใหญ่ — ลดราคาให้ต่ำกว่า comps ที่ใกล้เคียงที่สุด
- **กฎ 180 วัน (เพดานเวลาถือครอง):** ตัดขายที่ราคาที่ขายได้ **บ้านที่ขายไม่ออกกินสภาพคล่องจนธุรกิจตาย เร็วกว่าการขายขาดทุนหนึ่งหลัง**

**Gate เข้าสู่ S6:** ประกาศขึ้นครบทุกช่องทาง + เบอร์/LINE ตอบได้จริง + มีคนพร้อมรับสายในเวลาทำการ

# S6 — รับลูกค้า + คัดเกรด (Lead Capture & Qualification)

**Owner:** Admin/Chat (บอท + คน) · **SLA:** ตอบครั้งแรก ≤ 5 นาทีในเวลาทำการ · **KPI:** เวลาตอบครั้งแรก, สัดส่วน Lead ที่คัดเกรดครบภายใน 24 ชม.

> **ตัวเลขที่ต้องท่องให้ขึ้นใจ:** Lead ที่ถูกทิ้งไว้เกิน 1 ชั่วโมง โอกาสปิดลดลงอย่างมาก
> ในธุรกิจนี้ **ความเร็วในการตอบ ชนะทุกอย่าง** — ชนะราคา ชนะบ้านสวยกว่า ชนะโฆษณาแพงกว่า

## 6.1 ขั้นตอนตั้งแต่วินาทีที่ลูกค้าทัก

| นาทีที่ | เกิดอะไร | ใคร/อะไรทำ |
|---|---|---|
| 0 | ลูกค้าทัก LINE OA / โทร / คอมเมนต์ | — |
| 0–1 | **บอทตอบทันที** ทักทาย + ตอบคำถามจาก FAQ + ขอชื่อและเบอร์ + ส่งการ์ดตัวเลขของบ้านที่ถาม | LINE bot (โค้ดที่มีอยู่) |
| 1–5 | บอทเริ่มคัดกรองด้วยคำถามชุด 7 ข้อ (ถามทีละข้อ ไม่ยิงรวด) | LINE bot |
| ≤15 | **คนจริงเข้ามาต่อ** ทักด้วยชื่อลูกค้า อ้างถึงสิ่งที่คุยกับบอทไปแล้ว | Admin/Chat |
| ≤60 | บันทึกลง Sheet แท็บ `leads` ครบทุกฟิลด์ + ให้เกรด A/B/C/D | Admin/Chat |
| ≤24 ชม. | ส่งต่อตามเกรด + กำหนด `next_action` และ `next_action_date` | Admin/Chat |

**นอกเวลาทำการ:** บอทตอบทันทีเสมอ + แจ้งเวลาที่คนจริงจะตอบ + คนจริงตามภายใน 09:00 วันถัดไป

## 6.2 คำถามคัดกรอง 7 ข้อ (ต้องได้ครบภายใน 24 ชม.)

ถามอย่างเป็นธรรมชาติ สอดแทรกในบทสนทนา **ห้ามยิงเหมือนแบบฟอร์มราชการ**

| # | คำถาม | ใช้ทำอะไร |
|---|---|---|
| 1 | *"ตอนนี้เช่าอยู่เดือนละเท่าไรคะ อยู่กันกี่คน"* | รู้กำลังผ่อนจริง + ขนาดบ้านที่ต้องการ + เปิดประเด็น "เช่า vs ซื้อ" |
| 2 | *"ทำงานอะไรคะ มีสลิปเงินเดือนหรือเป็นอาชีพอิสระ"* | ตัวแปรสำคัญที่สุดในการเลือกธนาคาร |
| 3 | *"ตอนนี้มีผ่อนอะไรอยู่บ้างคะ รถ บัตรเครดิต บัตรกดเงินสด กยศ."* | คำนวณ DSR |
| 4 | *"เคยมีค้างชำระหรือเคยตรวจเครดิตบูโรไหมคะ"* | ถามให้เบา ไม่ตัดสิน — ตัวชี้ว่าจะเป็นเกรด B หรือ C |
| 5 | *"มีเงินเก็บเตรียมไว้ประมาณเท่าไรคะ (สำหรับดาวน์ + ค่าโอน + ค่าใช้จ่ายวันโอน)"* | คัดคนที่พร้อมจริง + ป้องกันดีลล่มวันโอน |
| 6 | *"อยากได้แถวไหนคะ ต้องใกล้อะไรเป็นพิเศษไหม (ที่ทำงาน / โรงเรียนลูก)"* | จับคู่ทรัพย์ + ข้อมูลป้อนกลับไปที่ S1 |
| 7 | *"ถ้าเจอบ้านที่ใช่ อยากย้ายเข้าประมาณเมื่อไรคะ"* | วัดความเร่งด่วนจริง |

## 6.3 การให้คะแนนความพร้อมกู้ (Bankability Score) — คำนวณอัตโนมัติได้

```
คะแนน = 0
+ 30  ถ้ามีเอกสารรายได้ครบ (สลิป + statement)     |  +15 ถ้ามีบางส่วน  |  +0 ถ้าไม่มี
+ 25  ถ้า DSR หลังรวมค่าผ่อนบ้านใหม่ ≤ 40%          |  +15 ถ้า 40–50%   |  +5 ถ้า 50–60%  | +0 ถ้า >60%
+ 20  ถ้าบูโรไม่เคยมีประวัติค้างชำระ                |  +10 ถ้าเคยแต่ปิดแล้วเกิน 12 เดือน  | +0 ถ้ายังค้าง
+ 15  ถ้ามีเงินสดพอสำหรับดาวน์ + ค่าโอน            |  +8 ถ้ามีครึ่งหนึ่ง  |  +0 ถ้าไม่มี
+ 10  ถ้าอายุงานปัจจุบัน ≥ 1 ปี (หรือค้าขายที่เดิม ≥ 2 ปี)

เกรด:  A = 80–100   |   B = 55–79   |   C = 30–54   |   D = < 30
```
> คะแนนนี้เป็น **เครื่องมือจัดลำดับงานภายใน** ไม่ใช่คำตัดสินของธนาคาร
> ห้ามบอกลูกค้าว่า "คุณคะแนน 42 กู้ไม่ผ่าน" — ให้บอกว่า *"ตอนนี้ยังมีบางจุดที่ต้องจัดก่อนค่ะ เดี๋ยวเราช่วยวางแผนให้"*

## 6.4 การส่งต่อตามเกรด (Routing)

| เกรด | ส่งต่อไปที่ | การกระทำแรก | ภายใน |
|---|---|---|---|
| **A** | Sales Closer | นัดดูบ้าน + เตรียมเอกสารยื่นกู้ล่วงหน้า | 72 ชม. |
| **B** | Credit Officer + Sales | เข้าโปรแกรมปั้นเครดิต 90 วัน **และ** พาดูบ้าน 1 หลังเพื่อสร้างเป้าหมายที่จับต้องได้ | 7 วัน |
| **C** | Credit Officer | นัดคุยวางแผนการเงิน 30 นาที + เข้ากลุ่มดูแลระยะยาว + เสนอทางเลือกเช่าออม/ผ่อนดาวน์ | 14 วัน |
| **D** | ระบบอัตโนมัติ | ส่งคู่มือ "เตรียมตัวก่อนซื้อบ้าน" ฟรี + เชิญเข้ากลุ่ม + ทักทายทุก 90 วัน | อัตโนมัติ |

## 6.5 มาตรฐานการพาชมบ้าน (Viewing)

**ก่อนไป**
- ยืนยันนัด 1 วันล่วงหน้า + เช้าวันนัดอีกครั้ง (ลดการเบี้ยวได้มาก)
- เปิดบ้านล่วงหน้า 30 นาที เปิดไฟทุกดวง เปิดแอร์ เปิดหน้าต่างระบายอากาศ ตรวจความสะอาด
- เตรียมแฟ้ม: การ์ดตัวเลข, ผังบ้าน, ตารางค่าใช้จ่ายวันโอน, ใบเปรียบเทียบเช่า-ผ่อน, เอกสารเกรดน้ำ+รูปช่วงน้ำท่วม, ใบรับประกันงานรีโนเวท

**ระหว่างชม (ลำดับที่ได้ผล)**
1. ยืนหน้าบ้าน คุยเรื่อง**ชุมชนและทำเล**ก่อนเข้าบ้าน (ตลาด โรงเรียน รพ. เวลาเดินทาง)
2. เข้าบ้านทางประตูหลัก → ห้องนั่งเล่น → **ครัว** → ห้องน้ำ → ห้องนอน → หลังบ้าน
3. **ชี้ให้ดูงานที่ซ่อนอยู่** — "ตรงนี้เดินไฟใหม่หมดครับ นี่รูปตอนเดิน" (แสดงรูประหว่างทำจากมือถือ) ← สร้างความน่าเชื่อถือมากกว่าคำพูดใดๆ
4. **พูดเรื่องน้ำท่วมก่อนที่ลูกค้าจะถาม** — "บ้านหลังนี้เกรด B ครับ ปี 68 น้ำขังถนนหน้าบ้าน 20 ซม. ไม่เข้าบ้าน นี่รูปจากเพื่อนบ้านตอนนั้นครับ และเราติดแพ็กสู้น้ำให้ครบแล้ว" ← **การพูดก่อนคือการควบคุมเรื่องเล่า**
5. ปิดท้ายที่ครัวหรือห้องนั่งเล่น หยิบการ์ดตัวเลขขึ้นมาคุยเรื่องเงิน

**คำถามปิดที่ใช้จริง**
- *"ถ้าเทียบกับค่าเช่าที่จ่ายอยู่ตอนนี้ พี่รู้สึกยังไงกับตัวเลขนี้ครับ"*
- *"มีตรงไหนที่ยังไม่ตรงใจไหมครับ ผมอยากรู้จริงๆ จะได้หาหลังที่ใช่กว่านี้ให้"*
- *"ถ้าเรื่องกู้จัดการได้ พี่พร้อมจะเริ่มขั้นตอนเลยไหมครับ"*

**หลังชม (ภายใน 2 ชั่วโมง)**
- ส่งสรุปทาง LINE: รูป 5 ใบที่ลูกค้าชอบที่สุด + การ์ดตัวเลข + ขั้นตอนถัดไปที่ชัดเจน
- บันทึกลง Sheet: ความเห็น, ข้อกังวล, สิ่งที่ชอบ/ไม่ชอบ, `next_action`
- **ข้อมูลจากคนที่ปฏิเสธมีค่ามากที่สุด** — ถามเหตุผลจริงและบันทึกไว้ เพราะนี่คือข้อมูลป้อนกลับไปแก้ S1/S4/S5

**Gate เข้าสู่ S7:** ลูกค้าให้ข้อมูลการเงินครบ + เซ็นใบยินยอม PDPA + ตกลงเข้ากระบวนการยื่นกู้หรือปั้นเครดิต

# S7 — ปั้นเครดิต + ยื่นกู้ (Credit Engineering & Loan)

**Owner:** Credit Officer · **SLA:** ประเมินเบื้องต้นภายใน 3 วัน · ยื่นกู้ภายใน 14 วันหลังเอกสารครบ · **KPI:** **อัตราอนุมัติสินเชื่อ ≥ 70%** (นี่คือ KPI ที่สำคัญที่สุดของทั้งบริษัท)

📖 **รายละเอียดเต็มอยู่ใน [03-credit-engine.md](03-credit-engine.md)** — สรุปกระบวนการที่นี่

```
ตรวจบูโร + คำนวณ DSR  →  วางแผนแก้รายบุคคล  →  ปิด/ปรับหนี้ตามลำดับ
        │                                              │
        │                                    สร้างหลักฐานรายได้ + เดินบัญชี
        │                                              │
        └──────────────►  เลือกธนาคารที่ตรงกับโปรไฟล์  ─┘
                                    │
                         ยื่น 2 ธนาคาร (หลัก + สำรอง)
                                    │
                    ┌───────────────┴───────────────┐
                 อนุมัติ                          ไม่อนุมัติ
                    │                                │
                  → S8                     ขอเหตุผลเป็นลายลักษณ์อักษร
                                                     │
                                          กลับเข้าโปรแกรมรอบใหม่
                                          (ห้ามปล่อยลูกค้าหลุดมือ)
```

**หลักการที่ห้ามละเมิด:**
- ❌ ห้ามทำเอกสารเท็จ สลิปปลอม หรือแต่งบัญชีให้ดูดีเกินจริง — ผิดกฎหมายและทำลายธุรกิจถาวร
- ❌ ห้ามอ้างว่า "ลบประวัติบูโรได้" — ทำไม่ได้ และใครอ้างว่าทำได้คือมิจฉาชีพ
- ❌ ห้ามยัดลูกค้าให้กู้เกินกำลัง
- ✅ สิ่งที่เราทำคือ **จัดระเบียบหนี้ · สร้างหลักฐานรายได้ที่มีอยู่จริงให้ธนาคารเห็น · เลือกธนาคารที่ตรงกับโปรไฟล์ · เตรียมเอกสารให้ครบและถูกต้อง** เท่านั้น

# S8 — ปิดการขาย + โอน (Closing & Transfer)

**Owner:** Sales Closer + Credit Officer · **SLA:** จากอนุมัติสินเชื่อถึงวันโอน ≤ 30 วัน · **KPI:** อัตราดีลล่มหลังอนุมัติ ≤ 5%

## 8.1 ลำดับขั้น

| ขั้น | กิจกรรม | ผู้รับผิดชอบ | จุดที่พลาดบ่อย |
|---|---|---|---|
| 1 | ทำสัญญาจะซื้อจะขาย + รับเงินมัดจำ | Sales + ทนาย | ระบุวันโอนและเงื่อนไข "หากกู้ไม่ผ่านคืนมัดจำ" ให้ชัด |
| 2 | ยื่นเอกสารเข้าธนาคาร | Credit Officer | เอกสารไม่ครบ = เสียเวลา 2 สัปดาห์ ใช้ checklist ทุกครั้ง |
| 3 | **ธนาคารเข้าประเมินราคาหลักประกัน** | Sales | ⚠️ **จุดตายอันดับ 2** — ดูข้อ 8.2 |
| 4 | รออนุมัติ + ติดตามทุก 3 วัน | Credit Officer | เงียบหายไม่ตาม = ดีลค้างในระบบเป็นเดือน |
| 5 | รับหนังสืออนุมัติ → นัดวันโอน | Credit Officer | ตรวจวงเงินและเงื่อนไขในหนังสือให้ละเอียด |
| 6 | **แจ้งค่าใช้จ่ายวันโอนเป็นตัวเลขจริง ล่วงหน้า ≥ 7 วัน** | Sales | ⚠️ **จุดตายอันดับ 3** — ดูข้อ 8.3 |
| 7 | วันโอน ณ สำนักงานที่ดินอำเภอหาดใหญ่ | ทุกฝ่าย | ไปถึงก่อนเวลา เตรียมเอกสารครบ |
| 8 | ส่งมอบบ้าน + เดินตรวจ 40 จุด | Sales + Reno PM | ให้ลูกค้าเซ็นรับมอบพร้อมรายการที่ต้องแก้ (ถ้ามี) |

## 8.2 ⚠️ ราคาประเมินของธนาคารต่ำ — เตรียมรับมือล่วงหน้า

ธนาคารปล่อยกู้ตาม **ราคาประเมินของธนาคาร** หรือราคาซื้อขาย *แล้วแต่อันไหนต่ำกว่า*
ประเมินต่ำ = ลูกค้าต้องหาเงินสดมาเติมส่วนต่าง = **ดีลล่มทั้งที่อนุมัติแล้ว**

**วิธีป้องกัน:**
1. **รู้ราคาประเมินราชการก่อนซื้อ** (ตั้งแต่ S2) และอย่าตั้งราคาขายห่างจากตลาดจริงมากเกินไป
2. **เตรียมแฟ้มให้เจ้าหน้าที่ประเมิน** ในวันที่เขามา: comps 3 รายการที่ปิดจริง + รายการงานรีโนเวทพร้อมใบเสร็จ + รูป Before/After + BOQ
3. **ทำบ้านให้พร้อมวันประเมิน** — สะอาด ไฟติดทุกดวง สวนเรียบร้อย เหมือนวันพาลูกค้าชม
4. **อยู่ด้วยตอนประเมิน** พาเดินและอธิบายงานที่ทำ อย่าปล่อยให้เขาเดินดูเองแล้วเดา
5. ถ้าประเมินต่ำ: ขอทบทวนพร้อมเอกสารประกอบ หรือยื่นธนาคารสำรองคู่ขนาน

## 8.3 ⚠️ ค่าใช้จ่ายวันโอน — ต้องแจ้งเป็นตัวเลขจริงล่วงหน้า

**สาเหตุอันดับต้นๆ ที่ดีลล่มวันโอนคือลูกค้าไม่รู้ว่าต้องมีเงินสดเท่านี้**
ทำ "ใบประมาณการค่าใช้จ่ายวันโอน" ให้ลูกค้าตั้งแต่วันแรกที่คุยกัน แล้วอัปเดตอีกครั้งก่อนโอน 7 วัน

| รายการ | ปกติใครจ่าย | ฐานคำนวณ |
|---|---|---|
| ค่าธรรมเนียมการโอนกรรมสิทธิ์ | ตกลงกัน (มักคนละครึ่ง) | % ของราคาประเมินราชการ |
| ค่าจดจำนอง | ผู้ซื้อ | % ของวงเงินกู้ |
| อากรแสตมป์ **หรือ** ภาษีธุรกิจเฉพาะ | ผู้ขาย | ขึ้นกับระยะเวลาถือครองและเงื่อนไขทางภาษี |
| ภาษีเงินได้หัก ณ ที่จ่าย | ผู้ขาย | ตามหลักเกณฑ์กรมสรรพากร |
| ประกันอัคคีภัย | ผู้ซื้อ | ตามเงื่อนไขธนาคาร (มักบังคับ) |
| ค่าประเมินหลักประกัน | ผู้ซื้อ | ตามธนาคาร |
| ค่าโอนมิเตอร์น้ำ–ไฟ, ค่าส่วนกลางล่วงหน้า | ผู้ซื้อ | ตามหน่วยงาน |
| ค่าดำเนินการ/ทนาย (ถ้ามี) | ตกลงกัน | — |

> ⚠️ **อัตราทุกตัวข้างต้นเปลี่ยนตามกฎหมายและมาตรการรัฐในแต่ละปี**
> ห้ามใช้ตัวเลขจากเอกสารนี้ ให้โทรถามสำนักงานที่ดินอำเภอหาดใหญ่และเจ้าหน้าที่สินเชื่อทุกครั้งก่อนแจ้งลูกค้า

**เคล็ดลับปิดการขาย:** เสนอ **"ช่วยค่าโอน" หรือ "ออกค่าใช้จ่ายวันโอนให้"** แทนการลดราคา
ต้นทุนเราเท่ากันหรือน้อยกว่า แต่แก้ปัญหาที่แท้จริงของลูกค้า (เขาไม่มีเงินสดก้อนนั้น) และไม่ทำให้ราคาประเมินในตลาดตก

## 8.4 ส่งมอบบ้าน

- เดินตรวจ **checklist 40 จุด** พร้อมกัน ถ่ายรูปทุกจุดที่ต้องแก้
- ส่งมอบ **คู่มือบ้าน**: ผังไฟ/ผังท่อ, ใบรับประกันเครื่องใช้, รายชื่อช่างที่ทำงานแต่ละระบบ, เบอร์ฉุกเฉิน, วิธีใช้แผงกั้นน้ำ
- **ใบรับประกันงานรีโนเวท 6–12 เดือน** (งานระบบไฟ/ประปา/รั่วซึม) ← ข้อนี้ทำให้เราต่างจากคนขายบ้านมือสองทั่วไปอย่างสิ้นเชิง
- มอบของขวัญขึ้นบ้านใหม่ + **ถ่ายรูปวันรับกุญแจ** (คอนเทนต์ที่มีพลังที่สุดในธุรกิจนี้ — ขออนุญาตก่อนใช้เสมอ)

# S9 — หลังการขาย + บอกต่อ (After-sales & Referral)

**Owner:** Admin/Chat + เจ้าของ · **KPI:** สัดส่วนดีลที่มาจากการบอกต่อ (เป้า ≥30% ในปีที่ 2), คะแนนความพึงพอใจ

## 9.1 ปฏิทินติดตามลูกค้า

| เวลา | ทำอะไร | เหตุผล |
|---|---|---|
| วันที่ 7 | โทรถามหลังย้ายเข้า + รับรายการงานเก็บตก | แก้ปัญหาเล็กก่อนกลายเป็นเรื่องใหญ่ |
| วันที่ 30 | เยี่ยมบ้าน + ถ่ายรูป/วิดีโอรีวิว (ขออนุญาต) | ได้คอนเทนต์ที่มีพลังที่สุด + ตรวจงานรับประกัน |
| วันที่ 90 | ตรวจสภาพงานรีโนเวท + **ขอแนะนำเพื่อนอย่างเป็นทางการ** | จังหวะที่ลูกค้าพอใจสูงสุดและยังตื่นเต้นอยู่ |
| ทุกปี | ทักวันครบรอบวันโอน + เตือนต่อประกันอัคคีภัย | ต้นทุนต่ำ ความประทับใจสูง |
| ปีที่ 3 | เสนอ **รีไฟแนนซ์** (หลังพ้นช่วงห้ามไถ่ถอนก่อนกำหนด) | ช่วยลูกค้าประหยัดดอกเบี้ยจริง + สร้างรายได้รอบสองให้เรา |

## 9.2 ระบบบอกต่อ (Referral)

- **ค่าแนะนำ 5,000–15,000 บาท ต่อดีลที่ปิดได้** หรือให้เป็นของ (แอร์ / เครื่องซักผ้า / ค่าส่วนกลาง 1 ปี)
- ประกาศให้ชัดตั้งแต่วันส่งมอบ ไม่ใช่ไปขอทีหลัง
- จ่ายทันทีและประกาศให้เห็น (โพสต์ขอบคุณผู้แนะนำ พร้อมภาพ) → คนอื่นเห็นว่าจ่ายจริง

## 9.3 ⭐ ชุมชน "คนอยากมีบ้านหาดใหญ่" — สินทรัพย์ระยะยาวที่สำคัญที่สุด

สร้างกลุ่ม LINE/Facebook เปิดรับ**ทุกคน** โดยเฉพาะกลุ่ม C และ D ที่ยังกู้ไม่ผ่าน

**สิ่งที่ให้ในกลุ่ม (ฟรีทั้งหมด):**
- ความรู้เรื่องเครดิตบูโร, DSR, การเตรียมตัวกู้, ทางเลือกสินเชื่อ
- อัปเดตบ้านใหม่ก่อนใคร
- ไลฟ์ตอบคำถามเดือนละครั้ง
- เรื่องราวคนที่เคยกู้ไม่ผ่านแล้วผ่าน ← คอนเทนต์ที่ทรงพลังที่สุด
- ความรู้เรื่องน้ำท่วม การเตรียมบ้าน การเคลมประกัน (สร้างความน่าเชื่อถือในพื้นที่)

**ทำไมถึงสำคัญ:** กลุ่ม C ใช้เวลา 6–24 เดือนกว่าจะพร้อม
นายหน้าทั่วไปเสียลูกค้ากลุ่มนี้ไป 100% เพราะไม่มีที่ให้เขาอยู่ระหว่างรอ
เราเก็บเขาไว้ในกลุ่ม ให้คุณค่าทุกเดือน → วันที่เขาพร้อม เขาไม่ไปหาใครอื่น
**ในปีที่ 3 กลุ่มนี้จะกลายเป็นแหล่งลูกค้าที่ต้นทุนต่ำที่สุดและปิดง่ายที่สุดของธุรกิจ**
