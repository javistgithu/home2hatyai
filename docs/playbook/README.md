## อ่านตรงนี้ก่อน — 5 ประโยคที่สรุปทั้งธุรกิจ

1. **เราไม่ได้ขายบ้าน เราขายการเปลี่ยนสถานะ "ผู้เช่า" ให้เป็น "เจ้าของ"** — สินค้าคือบ้าน แต่บริการที่ลูกค้าจ่ายเงินให้จริงคือ *การพาเขาให้กู้ผ่าน*
2. **กำไรเกิดตอนซื้อ ไม่ใช่ตอนขาย** — ซื้อผิดราคาแค่ 5% กินกำไรทั้งดีล ไม่มีการตลาดใดกู้ดีลที่ซื้อแพงคืนมาได้
3. **ตัวชี้วัดหลักคือ "ต้นทุนต่อลูกค้าที่กู้ผ่าน 1 คน" ไม่ใช่ต้นทุนต่อ lead** — lead 100 คนที่กู้ไม่ผ่าน มีค่าเท่ากับศูนย์
4. **ที่หาดใหญ่ "เกรดน้ำท่วม" คือตัวแปรราคาอันดับหนึ่งที่คนนอกพื้นที่มองข้าม** — เราทำให้มันเป็นจุดขาย ไม่ใช่ความลับ
5. **ลูกค้าที่ยังกู้ไม่ผ่านวันนี้ คือสินทรัพย์ ไม่ใช่ขยะ** — นายหน้าทั่วไปทิ้ง เราเก็บไว้ปั้น 3–24 เดือน นี่คือคูเมืองของธุรกิจนี้

## ข้อจำกัดของเอกสารนี้ (อ่านให้ครบ)

- **ตัวเลขทุกตัวในคู่มือนี้เป็น "สมมติฐานตั้งต้น" (placeholder)** ไว้ให้เริ่มคิด ไม่ใช่ข้อมูลตลาดที่ยืนยันแล้ว
  ต้องแทนที่ด้วยตัวเลขจริงจากการสำรวจของคุณเองภายใน 60 วันแรก — ดูวิธีเก็บใน [05-unit-economics.md](05-unit-economics.md)
- **เรื่องภาษี ค่าธรรมเนียมโอน มาตรการรัฐ LTV และเงื่อนไขสินเชื่อ เปลี่ยนทุกปี** เอกสารนี้บอก *โครงสร้าง* ให้ ไม่ใช่ *อัตราปัจจุบัน*
  ต้องยืนยันกับสำนักงานที่ดินอำเภอหาดใหญ่ สรรพากรพื้นที่ และเจ้าหน้าที่สินเชื่อสาขา ก่อนใช้ตัวเลขจริงเสมอ
- **ไม่ใช่คำแนะนำทางกฎหมาย ภาษี หรือการลงทุน** — สัญญาจะซื้อจะขาย สัญญาเช่าออม และโครงสร้างบริษัท ต้องให้ทนายและนักบัญชีตรวจก่อนใช้
