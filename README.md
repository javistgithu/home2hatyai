# อยากมีบ้านหาดใหญ่ — ระบบรวมประกาศบ้านและที่ดิน

แอปพลิเคชันรวมประกาศขายบ้าน/ที่ดินจากหลายแหล่ง มาคัดข้อมูลซ้ำ ระบุพิกัด GPS
แล้วแสดงบน Google Maps ออกแบบสำหรับมือถือ ใช้ Supabase เป็นฐานข้อมูล
รองรับผู้ใช้ 3 ระดับ: **ผู้ดูแลระบบ / ผู้ขาย / ผู้ซื้อ**

---

## ระบบทำอะไรได้บ้าง

**เก็บข้อมูล → คัดซ้ำ → ปักหมุด → แสดงผล**

```
โพสต์จากกลุ่ม/เพจ ──┐
ผู้ขายลงเอง        ──┼──▶ แปลงข้อความไทยเป็นข้อมูลมีโครงสร้าง
ไฟล์ CSV / JSON    ──┘         │
                               ▼
                     คัดโพสต์ที่ไม่ใช่ประกาศออก (โพสต์ตามหา/รับซื้อ)
                               │
                               ▼
                     หาพิกัด GPS (โพสต์ → ลิงก์แผนที่ → Geocoding → ตำบล)
                               │
                               ▼
                     ให้คะแนนความซ้ำ 0-100 → รวมอัตโนมัติ / ส่งแอดมินตรวจ
                               │
                               ▼
                     แสดงบนแผนที่ + รายการ พร้อมฟิลเตอร์
```

### สำหรับผู้ซื้อ
- ค้นหาด้วยคำ ฟิลเตอร์ราคา/ประเภท/พื้นที่/ห้องนอน/ตำบล
- แผนที่ Google Maps พร้อมป้ายราคาและการรวมกลุ่มหมุด (clustering)
- ประกาศที่รู้ตำแหน่งแค่คร่าว ๆ แสดงเป็น **วงพื้นที่** ไม่ใช่หมุด เพื่อไม่ให้เข้าใจผิด
- บันทึกรายการโปรด ดูประกาศใกล้เคียง กดโทร/แชท LINE ได้ทันที

### สำหรับผู้ขาย
- ลงประกาศพร้อมปักหมุดบนแผนที่
- **วางข้อความประกาศเดิม แล้วระบบเติมข้อมูลให้อัตโนมัติ** (ราคา พื้นที่ ห้อง เบอร์ ที่ตั้ง)
- ดูยอดเข้าชม และรายชื่อผู้สนใจที่กดดูเบอร์
- แก้ไข/ทำเครื่องหมายว่าขายแล้ว/เก็บเข้ากรุ

### สำหรับผู้ดูแลระบบ
- แดชบอร์ด: จำนวนประกาศ ความครอบคลุมพิกัด คุณภาพข้อมูล แยกตามอำเภอ/ประเภท/แหล่งที่มา
- คิวอนุมัติประกาศ พร้อมคำเตือนอัตโนมัติ (ไม่มีราคา/ไม่มีเบอร์/พิกัดไม่แม่น)
- หน้าตรวจรายการซ้ำ แสดงคะแนนและเหตุผลเทียบกันทีละคู่
- คอนโซลนำเข้าข้อมูลแบบวางข้อความ พร้อมดูผลการแปลงทันที
- จัดการแหล่งข้อมูล ผู้ใช้ และบทบาท

## เริ่มใช้งาน

```bash
npm install
cp .env.example .env.local     # ใส่ค่า Supabase และ Google Maps
npm run dev
```

จากนั้นรันไฟล์ SQL ใน `supabase/migrations/` ตามลำดับ 0001 → 0004 ที่ Supabase SQL Editor

## คำสั่งที่ใช้บ่อย

```bash
npm run dev              # เปิดเซิร์ฟเวอร์สำหรับพัฒนา
npm run build            # สร้างไฟล์สำหรับ production
npm run test:parser      # ทดสอบตัวแยกข้อมูลกับโพสต์ตัวอย่าง
npm run import:samples   # นำเข้าข้อมูลตัวอย่าง (ต้องตั้ง APP_URL + INGEST_SECRET)
npm run collect:facebook # เก็บจากกลุ่ม/เพจที่คุณเป็นแอดมิน (ดู DATA-COLLECTION.md)
```

## เทคโนโลยีที่ใช้

- **Next.js 14** (App Router, Server Components, Server Actions)
- **Supabase** — PostgreSQL + Auth + Row Level Security
- **Google Maps JavaScript API** + Geocoding API
- **TypeScript** ทั้งโปรเจกต์ ไม่มีไลบรารี UI ภายนอก (CSS เขียนเอง ~370 บรรทัด)

---

## ⚠️ ข้อควรทราบเรื่องการเก็บข้อมูล

ระบบนี้ **ไม่มีตัวดูดข้อมูลอัตโนมัติจากกลุ่ม Facebook ที่คุณไม่ได้เป็นแอดมิน**
เพราะการทำเช่นนั้นผิดข้อกำหนดการใช้งานของ Meta และเสี่ยงถูกระงับบัญชี

ช่องทางที่ระบบรองรับคือ Facebook Graph API สำหรับกลุ่ม/เพจของคุณเอง,
การคัดลอกข้อความมาวาง, การนำเข้าไฟล์ CSV/JSON และ API สำหรับตัวเก็บข้อมูลภายนอก

อ่านรายละเอียดและทางเลือกที่ถูกต้องได้ที่ [docs/DATA-COLLECTION.md](docs/DATA-COLLECTION.md)
